## Exactness argument

Put `A=Q[all original G coordinates,c]`; the canonical ring is
`A[y,x]` written as `Q[y,x,G,c]` with the y-first block order
`(lp(1),dp(...))`.  The emitted

```text
h = y^K + h_lower,       deg_y(h_lower) < K
```

is monic.  For coefficient polynomials `a,b` and nonnegative `r,s`, the
product rule gives the identity

```text
J(a*h^r,b*h^s)
 = h^(r+s) J(a,b)
 + h^(r+s-1) (s*b*J(a,h) + r*a*J(h,b)).
```

The mixed `r*s` terms cancel.  Summing this identity over the exact P and Q
blocks therefore constructs the literal P-first Jacobian, not the opposite
orientation.  The script also rejects `BB1`, so beta_1 is exactly zero.

At formal level `i`, write the current coefficient uniquely as
`H_i=q_i*h+r_i` with `deg_y(r_i)<K`.  Replacing
`H_i*h^i` by `r_i*h^i+q_i*h^(i+1)` preserves the polynomial identically.
The sparse top-down division removes the current largest y-term using the
unit leading coefficient of `h`; hence it uses addition and multiplication
in `A[x]` only, has no denominators or branch, and is exactly the determinate
division selected by the canonical y-first ring.  Iteration yields the
unique monic h-adic expansion `sum_i r_i*h^i`.  Subtracting `c*x^ell` in the
`i=0`, `y=0` block is therefore exactly the canonical target operation.

Equivalently, the ordinary monomials and `y^r*h^i` (`0<=r<K`) are related on
every finite support by a unitriangular matrix over `A[x]`, with diagonal
one.  Expansion in x turns this into a finite block-unitriangular matrix over
`A`.  Thus the ideals generated by all ordinary `(x,y)` coefficients and by
all normalized h-adic `(i,x,y)` coefficients coincide in `A`; adjoining
`T*c-1` preserves equality.  The sparse implementation goes further: it
emits the canonical h-adic coefficients themselves.

The parser enumerates the variables from the unchanged ring line and asserts
that their count is the class `unknowns_without_T`.  Its base-polynomial
arithmetic is over integer coefficient dictionaries, which embeds exactly
in the declared rational ring.  There is no code path that deletes a G
coordinate, substitutes a value for one, or adds an auxiliary symbol.
