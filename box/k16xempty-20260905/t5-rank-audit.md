# Independent t=5 rank proof and literal chart unit circuits

**Verdict: both t=5 charts are unit ideals in characteristic zero.**
This audit independently rebuilds the selected coefficient matrix from
the fresh F3 source and reproduces its determinant modulo 32009 by a
different elimination implementation. It then constructs literal
characteristic-zero unit certificates as finite determinant circuits.
It makes no assertion about any t beyond five.

The producer's compact input is `linear_t5_rank_certificate.json`. It
declares a 1792-by-3504 weight-42 Macaulay matrix and specifies 1792
selected columns, each by its original residual row label k, its
cofactor monomial exponent vector, and its exact rational row scale.
The independent audit reads this data, but reads no producer matrix
export or elimination implementation.

`rank_minor_replay.py` instead imports the literal fresh
`controls_t5_raw.sing` in Singular, verifies target=B*eta, and exports
each individual exact coefficient and exponent of the nine residuals,
B, eta, and target. A separate Python parser interprets the exported
number-field expressions using pairs of exact rational numbers
(a,b)=a+b*d, with d^2=2. No floating-point arithmetic occurs.

It independently verifies:

- the raw F3 file SHA-256 matches the compact rank certificate;
- every exported coefficient denominator is a unit modulo 32009;
- the declared weights (1,2,3,4,6) give E_k weight22-k, B weight11,
  eta weight10, and B*eta weight21;
- enumerating every nonnegative exponent vector of weight42 gives
  exactly the 1792 monomials, in exactly the recorded basis order;
- the full source-multiple inventory has 3504 columns;
- the selected 1792 source-row/cofactor-monomial pairs are distinct
  and have precisely the required multiplier weights;
- every selected exact rational scale has prime-unit denominator
  and nonzero residue;
- after scaling, each selected coefficient is integral in e=3*d:
  a*scale and b*scale/3 are both integers;
- e^2=18, e maps to7868, d maps to23962, and 3*d=e modulo32009.

The audit constructs the selected 1792-by-1792 matrix from these
freshly exported coefficients. An independent NumPy program performs
integer Gaussian elimination with row pivoting modulo32009; the
producer used FLINT. All arithmetic is reduced at each update. The
largest un-reduced update magnitude is below 32009^2+32009, far below
the signed 64-bit integer limit. The independent determinant is

    det(A) mod (32009,e-7868) = 29155 != 0.

This is the producer's recorded value, including the sign associated
with the precise saved row and column order. The final audit marker
is `INDEPENDENT_T5_RANK_MODEL_AND_DETERMINANT_PASS`.

The characteristic-zero inference is an elementary determinant argument.
The exact selected matrix A has entries in the domain
Z[e]=Z[T]/(T^2-18), embedded in k=Q(sqrt2) by e=3*d. Evaluation at
e=7868 modulo32009 is a ring homomorphism. A zero element would have
zero image, so the nonzero determinant residue proves that the exact
determinant delta=det(A) is nonzero in k. Consequently A is invertible
over k, and its columns span the full weight-42 vector space. Every
weight-42 polynomial belongs to the ideal generated by the original
E_k, in particular (B*eta)^2.

This proof does not infer generic affine emptiness from one empty
special fibre. It verifies an explicit maximal minor of a finite exact
coefficient matrix. All specializations are used solely to prove that
this scalar determinant is nonzero. No properness hypothesis is used.
Because k is a field, a nonzero algebraic number remains nonzero under
both characteristic-zero embeddings; no second finite-field root is
needed for that conclusion at this irreducible index.

## Literal determinant certificates in the two declared chart rings

The compact characteristic-zero certificate can be written without
expanding large rational cofactor polynomials. Let m_i be the recorded
ordered weight-42 monomial basis, and let

    g_l=scale_l * monomial_l * E_(source_row_l).

Thus A[i,l]=[m_i]g_l. Set v_i=[m_i](B*eta)^2. For every selected
column l let h_l be the determinant obtained by replacing column l
of A by v. Cramer's polynomial identity A*h=det(A)*v gives

    tilde_a_k=sum_{l:source_row_l=k}h_l*scale_l*monomial_l,
    sum_k tilde_a_k*E_k=delta*(B*eta)^2.                (1)

These are finite arithmetic circuits in the exact declared scalar
coefficients. In particular delta and every h_l are scalars in k;
the cofactor monomials give tilde_a_k exactly weight20+k. The source
matrix and its row/column order determine every circuit input.

For k=2,...,10 the actual residual b degrees are

    d_k=(3,3,3,2,2,2,2,2,2),

and valid homogeneous cofactor degree caps are

    e_k=floor((20+k)/6)=(3,3,4,4,4,4,4,4,5).

Thus e_k+d_k<=7. Define

    C_e(f)=sum_{j=0}^e [b^j]f * A_slice^j * Delta^(e-j),
    F_k=C_(d_k)(E_k),
    Q_k=Delta^(7-e_k-d_k)*C_(e_k)(tilde_a_k).

Every exponent is nonnegative. Homogenizing (1) to b degree7 and
using the exact images
M*Delta+N*A_slice=rho*Delta+sigma*A_slice=H gives

    sum_k Q_k*F_k=delta*Delta^3*H^4.                  (2)

With P=u*Delta*H the literal main-chart certificate is

    1=sum_k (u^4*Delta*Q_k/delta)*F_k
      +(1+P+P^2+P^3)*(1-P).                         (3)

Division by delta is allowed in the coefficient field because its
nonvanishing was independently verified. No additional polynomial
denominator is used in these certificate coefficients.

For the complementary ring the exact source identity
B-eta=b*Delta-A_slice gives

    delta*B^4=sum_k tilde_a_k*E_k
      -delta*B^2*(eta+B)*(A_slice-b*Delta).

Therefore its literal unit certificate is

    1=sum_k (s^4*tilde_a_k/delta)*E_k
      -s^4*B^2*(eta+B)*A_slice
      +s^4*B^2*(eta+B)*b*Delta
      +(1+s*B+(s*B)^2+(s*B)^3)*(1-s*B).              (4)

`t5_rank_chart_circuit.py` binds these formulas to the saved actual
charts. Its fresh Singular replay checks all source/affine coefficient
identities, residual b degrees, and all nonnegative exponent bounds.
It recomputes every F_k from the original rows and checks its image
against the saved main chart in k[c1,c2,c3,c4,u]. It also checks every
original E row and B, Delta, A_slice against the saved boundary chart
in k[c1,c2,c3,c4,b,s], using the explicit coefficient-ring maps. Finally
it verifies the universal polynomial arithmetic in (3) and (4), with
delta kept as an independent scalar symbol. The final marker is
`T5_RANK_CHART_CERTIFICATE_ALL_ASSERTIONS_PASS`.

The deterministic circuit specification, input hashes, field and
generator orders are saved in `t5_rank_chart_circuit.json`. This proof
does not require reading or expanding the producer's subsequently
serialized 191-MiB source coefficient certificate.
