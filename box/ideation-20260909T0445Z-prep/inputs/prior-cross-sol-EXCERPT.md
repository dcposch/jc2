## 2. Proper-power reconstruction and the threshold proposal

Fable's useful observation is only the factor-level start: if a common leader
is `H=h^e`, replacing it by a primitive closed root changes the leading scalar
exponents from `(3,5)` to `(3e,5e)`. It does **not** preserve the old cubic/
quintic reference identity. Let the actual scalar references be `a(R),b(R)`
and divide in the scalar polynomial ring

```text
b'(z) = a'(z)q(z) + rho(z).
```

For `A=a(R)+F` and `B=b(R)+q(R)F+G`, direct factored bracket bookkeeping gives

```text
[A,B] = [R,T] + [F,G],
T = a'(R)G - rho(R)F - (q'(R)/2)F^2.
```

This identity is sound as a formal algebraic decomposition, but it is not a
source implication and does not establish `ord_s G >= 2j`. In the `(3e,5e)`
homogeneous ledger the first allowed derivative-remainder coefficient can
occur at order `(2e+1)d`, where `d=deg h`. Hence `rho(R)F` can have order
`(2e+1)d+j`, strictly before `2j` whenever `j>(2e+1)d`. The induction that
normalizes the leading coefficient of `G` must retain this term and every
kernel; the old `(3,5)` proof cannot be imported by renaming `H` to `h`.
Fable Card B explicitly includes `ord G>=2j` among its starting data and so
does not prove the claimed general late-contact bound. Its reduced-base
universality is, at most, an unreviewed reference *frame*; its main estimate is
`OPEN` in substance, though I introduce no new campaign OPEN identifier.

The first honest unequal proper-power method control is

```text
h = x*y^10,  e=2,  H=h^2,
tops h^6 and h^10, actual-degree scale (66,110).
```

Here `h` has two unequal coprime factor multiplicities, so the supplied
balanced-endpoint theorem does not reject it. The degree gcd is `22>=16` and
maximum degree `110>=108`, so the charged classical numerical screens do not
already close this scale; `D=21` would still have maximum `105<108`, making
`D=22` the first integer scale for this ratio beyond that screen. This remains
a method control, not a claimed Keller pair or a claim that arbitrary scalar
data arise from one. It is particularly discriminating without any expansion:
`d=11,e=2` gives first possible `rho` order `55`, while the natural late
inequality `3j>(8e-1)d=165` begins at `j=56`; throughout that late range the
`rho F` term can precede `F^2`. A proof must either derive its vanishing from a
literal source or replace the `2j` bound. Merely choosing coefficients that
make `rho=0` would be a predicate flip, not an attack on the full claim.

The Sol blind's separate finite-centralizer assertion

```text
deg_combined(T) <= N and ord_s[R,T] >= N  =>  [R,T]=0
```

survives my prose audit as an abstract candidate. Split `T` into combined-
homogeneous pieces; their brackets have distinct combined degrees. In a piece
of degree `n<=N`, every first coefficient at order `ell<n` lies in `K[H]` and
can be removed by the matching `s^ell R^i`; if `ell=n`, the coefficient has
ordinary degree zero and already commutes. Finite induction exhausts the
piece. This is still unreviewed cross mathematics, not promoted. Its only
stated application adds the equality boundary `3j=7D` (hence only the relevant
divisibility cases) to accepted15w. If the provisional whole closed-H screen
passes, that application has no actual source; if it fails, the packet still
names no attached client. Bank it as a method-control candidate and do not
spend a gate before a literal source makes equality decisive.
