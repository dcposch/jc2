One chosen representation: sparse Q-rational monomials in eight lower parameters,u,ell,d0,v0,v1,k1,k2,k3; Laurent unit s; bookkeeping S,t; and v-basis0..6 modulo the exact degree7 p. The format is width12 sorted exponent vectors and canonical numerator/positive-denominator STRINGS. Only s exponents may be negative on serialized polynomials. The product algebra is not treated as a field. Three named inverses L,w,f5 are computed by Q[v] Euclidean identities and independently multiplied back to1. No factorization or arbitrary quotient-coefficient division occurs.

## Fresh changed-object controls (designed only)

Each changed output must receive a separately registered hash and be rejected for the specified semantic reason, rather than solely failing a stale outer hash. No control payload has been generated.

- DROP-ROW: remove one retained row and matching retained ID; require the fixed all20/17 inventory to reject. A second mutation removes an actual nonzero constant term from both a retained row and its residual polynomial while keeping all other metadata synchronized; require full bracket/original-row read-back rejection.
- WRONG-INVERSE: alter one rational coefficient of a named inverse; require the exact product-to1 identity to fail. Do not select a field factor or invert an arbitrary coefficient.
- WRONG-SCALE: change the d1 mapping's s exponent from-1 to+1 and propagate it through claimed payloads if needed; the independently constructed scale mapping/original substitution must reject.
- WRONG-MODULUS: change p's constant coefficient by1; require exact unreduced modulus equality to reject, even if all output arithmetic was done modulo the altered polynomial.
- LAURENT: valid negative s exponents must be accepted on the genuine artifact; clamping one genuine negative exponent to0 must fail read-back. A negative exponent in u or S must fail the exponent-domain parser. These are distinct controls; rejecting all negative exponents is itself wrong.
- OMIT-POLE: remove one of the literal10 pole-map entries; require pole inventory rejection. Separately change a low A/B coefficient that creates a genuine inverse pole, with coefficient-slot wires synchronized; the direct substitution and/or full coefficient test must reject, not a sampled boundary evaluation.
- PRECISION: choose a genuine nonzero reduced monomial coefficient and replace its rational numerator by a canonical integer string strictly beyond2^53 that rounds differently through binary64 (record that precondition). Verify the exact parser retains its integer value; an actual JSON float must be rejected by type. A rounded integer disguised as a canonical string must fail full exact row read-back. Do not call a generic JSON roundtrip proof of unchanged artifact semantics.
- OMIT-LEADING: remove the saved a or b restoration slot or change B5; require explicit restoration/inventory/full bracket failure. Neither source monicity nor invertibility may be inferred from a row count alone.

All mutations are outstanding; no PASS, actual payload, optimized-mode evidence or numerical point is claimed. A separate finite control harness would need its own reviewed code/registration; this document is a validation plan, not a hidden dispatch script.
