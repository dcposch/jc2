# PURITY0820 companion: one common immersed image is a smooth A1

Assume the actual omitted boundary is nonempty, all E_i have ONE common irreducible image D, and every normalization branch of D is immersed. The local result in the main report applies at every omitted point, including self-intersections: delta_i=1, all slack is zero, and X is smooth there.
Put W=sum_i r_i. The accepted identities give W=e-1>=1 and #F^-1(y)=e-(e-1)b(y) for y in D, where b(y) is the number of normalization branches of D at y. Repeated source curves with image D all contribute to W.
If b(y)>=2 anywhere, nonnegativity gives 0<=e-2(e-1)=2-e, hence e<=2. Nonempty omitted boundary gives e>=2, so e=2 and W=1.
Since every r_i is a positive integer, W=1 means exactly one omitted E and r=1. The proved cyclic local model is then unramified at EVERY point of E. The actual h is already etale on U, so h is finite etale on all X.
The connected normal surface X therefore gives a connected finite etale cover of simply connected complex A2. Analytic covering theory forces e=1, contradicting e=2. This step uses the actual finite normalization, not a degree-foundation claim or an abstract monodromy surrogate.
Consequently b(y)=1 at every point of D. Every selected branch was assumed smooth, so D is smooth everywhere. Its accepted normalization is A1; a smooth curve equals its normalization, hence D is a smooth embedded A1 in A2.
UNCONDITIONAL CONCLUSION FROM THE PRESENT PACKET: if all omitted curves share one image and all its branches are immersed, that image must be a smooth embedded A1. The argument excludes every self-intersection of that common image.
CONDITIONAL INTERFACE ONLY: applying the prior accepted exclusion of an embedded-A1 component at its exact actual-Keller scope would rule out this case. Thus, conditional on that exclusion, an irreducible nonproper-value set of a nonproper Keller map must possess an intrinsically nonimmersed branch. Its old proof was not re-read or newly imported here.
This does not exclude an individual immersed image component when the nonproper-value set is reducible: the other images contribute to the pointwise count and the W=e-1 common-image argument no longer applies. The general global GAP verdict of the main report remains; its disposition should be read with this additional one-image restriction.
