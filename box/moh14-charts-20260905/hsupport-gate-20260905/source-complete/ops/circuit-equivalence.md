# Exact finite graph representation of the completed chart

The input is each **source-complete** fixed native builder, including its full
parameter list and literal polynomials `h`, `AAi`, and `BBj`. The circuit does
not impose any additional support cap, parameter value, or normalization.
`circuit_emit.py` parses only these primitive coefficient polynomials. Its
output is an exact finite graph extension of the same chart, not a slice.

Let R be the polynomial ring over Q in the intrinsic chart parameters, with
c among them. Write A_i for `AAi`, put B_1=0, and write B_j for `BBj`. The
source definitions are

    P = h^e + A_1 h^(e-1) + ... + A_e,
    Q = h^q + B_2 h^(q-2) + ... + B_q.

The emitter defines successive bivariate polynomial coefficient arrays by
Horner recursion P_0=Q_0=1, P_k=P_(k-1)h+A_k, Q_k=Q_(k-1)h+B_k. It retains the
**entire Minkowski-sum support** of each multiplication and the entire support
of the added primitive polynomial. Every nontrivial new coefficient receives
a fresh auxiliary u, with defining equation u-f=0. Here f is a polynomial in
intrinsic variables and auxiliaries from strictly earlier Horner stages.
Literal 1 and an unchanged existing variable are simply reused, with no new
coordinate. No zeroing of a source parameter occurs.

Order the auxiliary variables in their creation order. If E is the ideal of
all their defining equations, induction on that order proves a canonical ring
isomorphism R[U]/E ~= R: substitute the polynomial f for its new variable u.
The inverse is inclusion of R. In particular, the graph projection is an
isomorphism, not only a surjective map on geometric points. The value of c is
preserved.

On the last coefficient arrays the emitter forms every x,y coefficient of

    Q_x P_y - Q_y P_x - c x^ell.

For coefficient Q_(b,a) and P_(d,t), the product contributes
(b*t-a*d) Q_(b,a) P_(d,t) to x^(b+d-1)y^(a+t-1), unless this integer factor is
zero. Hence these rows are exactly the differential Jacobian coefficient
rows in the graph quotient. If I_xy is the full direct-coefficient ideal in
R, the extended circuit quotient by E plus these final rows is canonically
R/I_xy. Adjoining z*c-1 commutes with this isomorphism. A rational unit
certificate in the extended localized ideal therefore proves precisely the
same emptiness statement as a rational unit certificate in the original
completed localized chart.

The native builder uses the monic h-adic basis instead. Because h=y^K plus
terms of smaller y degree, the basis elements y^a h^r (0<=a<K) have leading
terms y^(a+Kr). The basis change to ordinary y powers is unitriangular over
R[x] on every finite degree segment, with polynomial inverse. Each family of
y coefficients lies in the R[x]-ideal generated by the other. Taking all
x coefficients proves equality of their coefficient ideals in R. Thus the
full native h-adic, full direct x,y, and triangular graph representations
have identical localized unit status.

The source orientation is Q_x P_y-Q_y P_x (low degree Q first), independently
checked against the fixed builder's raw H_i sum. Reversing the convention
only changes c to -c; that automorphism preserves localization at c.

This algebra proves equivalence generically. Tests check implementation: for
each of 11 completed fibres, two exact rational specializations (seeds 1 and
7, with c nonzero) evaluate every monic recurrence equation to zero. Separate
Singular scripts construct P and Q directly from h and the primitive A/B
polynomials using the displayed power expansions, differentiate them, and
compare with the numerical circuit Jacobian coefficient array. All 22
comparisons and all 22 negative controls pass. The separate direct-builder
controls also pass for two seeds in each of the same 11 fibres. These tests
are controls, not substitutes for the preceding generic ring argument.

`circuit-emission.json` records intrinsic and auxiliary counts, equation
counts, source builder hashes, row hashes, and exact control paths. The
msolve manifests independently bind the rows, metadata, source builder,
bijective variable map, field, and `z*c-1` to the emitted bytes. The initial
emitter refusal of repeated variable factors was repaired by writing powers
(e.g. `u^2` instead of `u*u`); no solver input from that refusal was run.

All 11 first circuit solver runs used official msolve 0.10.1 over
F_1073741827 with `-g 2 -l 44 -m 1000 -s 12 -u 8`, 8 threads, and a 900-second
watchdog. They terminated naturally before the watchdog with code 139 and
explicit exponent-vector allocation failure messages under their recorded
virtual-memory ceilings. An empty output is **neither UNIT nor NONUNIT**.
No exact-Q production unit was produced or promoted.

Two larger-memory retries followed, using byte-identical full inputs. The
r7i workers were externally terminated at 13:15:32 UTC before the planned
64 GiB preflights, so those two orchestration attempts invoked no solver.
On surviving workers, a 48 GiB capped native V3_8 input (111 intrinsic
variables; 175 localized generators) ran from 13:22:50 to 13:37:50 UTC and
reached the natural 900-second watchdog, return code 124. Its largest sampled
VmHWM was 7,437,220 KiB; the wrapper's timeout placement prevents claiming an
exact final GNU-time peak. The V3_2 graph retry (185 intrinsic + 395 auxiliary
variables; 885 localized generators) ran for 444.63 seconds before a new
allocation failure, return code 139, with GNU-time peak RSS 40,331,724 KiB.
The two expanded Mm15 representations each reached their own natural
900-second watchdog, return code 124. Every production output remained
empty, and no exact-Q confirmation was triggered. `final-solve-summary.json`
preserves all 37 computational/orchestration records with typed outcomes.
`final-operational-audit.json` records the cutoff and zero remaining lane
builder, solver, driver, or collector processes on the surviving hosts.
