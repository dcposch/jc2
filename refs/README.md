# Reference sources

Third-party papers and source snapshots belong here. Campaign-authored
analysis of those sources stays in `avenues/`, `ladder/`, or the relevant case.

`zheglov/` contains locally downloaded abstract/version pages and the v5 TeX
source. It was moved from the old top-level `zheglov/` directory and remains
Git-ignored. The [scope review](../avenues/ZHEGLOV-SCOPE.md) points to the new
location. These local downloads are not required to clone or use the rest of
the repository.
