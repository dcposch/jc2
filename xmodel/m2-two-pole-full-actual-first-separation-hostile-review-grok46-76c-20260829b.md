## 4. Attack 1 — physical flag tree

### 4.1 Ultrametric, including the max-over-representatives and `O(P,P)=infinity`

Definition 3.2 first assigns to two formal series of the same form the
first-difference index `min{j : c_j != c*_j}` with `j in Q+`.  For physical
places of the same side it then takes the **maximum** of that index over
corresponding Puiseux representatives; different sides get `O=-1`.
`O(P,P)` is not defined (the clause is `P != P*`).

Raw first-difference of formal series is an ultrametric.  Deck substitutions
`sigma_zeta : x^{1/kappa} |-> zeta x^{1/kappa}` multiply the coefficient at
exponent `j/kappa` by `zeta^{-j}` and therefore preserve raw contact.  If
`p,q` realize `O(P,Q)` and `q',s` realize `O(Q,S)` with `q'=sigma(q)`, then

```text
O(P,S) >= O(sigma p, s)
       >= min(O(sigma p, sigma q), O(q',s))
       =  min(O(P,Q), O(Q,S)).
```

Cross-side: if `P,R` share a side and `Q` does not, then
`O(P,Q)=O(Q,R)=-1` and `O(P,R)>=0`; if `P,R` differ in side then
`O(P,R)=-1` and the right-hand min is `-1`.  With the forced convention
`O(P,P):=infinity`, Definition 3.3 is an equivalence: reflexivity is the
convention, symmetry is symmetry of `O`, transitivity is the ultrametric.
This is exactly the nit at `ladder/SIGRAY-AUDIT.md:19`.  Sol's Lemma 2.1
runs the same argument on `Omega`; Opus Lemma A1 records both routes.  The
Omega-free route is the one that does not rest on Statement 3.2's missing
printed proof.

### 4.2 `I_P(t)=I_Q(t)` iff `t<=O(P,Q)`; unique rootward restriction; no remerging

Unwinding Definition 3.3 and Notation 3.1: class equality
`I_P(t)=I_Q(t)` is `(P,t)~(Q,t)`, which is `t<=O(P,Q)`.  The contact
`O(P,Q)` is one height-independent rational (or `-1`, or `infinity`), so
the predicate `t<=O(P,Q)` is downward-closed in `t`.  Therefore:

- if `I_P(t)=I_Q(t)` and `0<=t'<=t`, then `I_P(t')=I_Q(t')` (unique
  rootward restriction, representative-independent);
- if `I_P(t)!=I_Q(t)` and `t''>=t`, then `I_P(t'')!=I_Q(t'')` (no
  remerging);
- `{t : I_P(t)=I_Q(t)} = [0,O(P,Q)] cap [0,infinity]`, empty iff `O=-1`.

The last common flag of `I_P(s)` and `I_Q(t)` is at height
`min(s,t,O(P,Q))`.  This is strictly stronger than the vertex-level chain
tree MP0 (`ladder/SHEET6-MULTIPOLE.md:80`), which the MFE hostile review
correctly refused to promote to a point-level statement about `T_(a,cv)`.
