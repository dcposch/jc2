## 3. New mechanism and new connection

### 3.1 New mechanism — `ORB-FUSE`: merge rigidity is orbit fusion, and it is a gauge-free transport equation

**History label: `NEW`.** Synonym check performed before claiming this, against
`ladder/` and `xmodel/`: the closest recorded objects are St. 3.16's semi-
invariance `p_F(η) = η^l p̃(η^{ν_F})`, St. 3.18's unique-`ε` one-direction-per-
orbit law, `SHEET6-III.md` (S3)'s `p(η) = η^μ Π(η^ν − c_i^ν)` pattern, MP6(b)
equal-quotient, and the `R2.3(i)` proportional kill. None of these is a statement
about the *arithmetic of the orbit invariants* `c_e^ν`, and none observes the
fusion. The `orbit size e_S / stabilizer κ/e_S` language of the promoted
intrinsic exact-pair L3–L5 theorem is a *terminal boundary-place* statement about
a different object. `TEMPLATE-ATTACK.md`'s `a2ν2-imprimitive` kill is an
entry-level `gcd(κ̄_P, ν)` parity test, not this.

**The observation.** Two independent derivations agree on the U1 coefficient
answer. My Theorem E gives, for any `r >= 2` equal-arrival merge with equal
multiplicity `μ`, free 0-root multiplicity `ε`, `k = lex = 0`:

```text
Prop. 8.1(iv) is solvable, admissibly, iff  Rad(t) = t^r - A  with A != 0,
i.e.  e_1 = ... = e_{r-1} = 0  on the arrival bases {c_e^nu},
and then C = -nu*r*(mu - eps)*A/dq != 0 automatically, uniformly in nu.
```

Grok's independent parametric solve on the reviewed `td=8` family is the `r=2`,
`μ=3`, `ε=0` instance: the reduced ODE collapses to a degree-two identity whose
`t^2` coefficient vanishes identically by Cor. 6.1 and whose `t^1` coefficient is
`-σ·3ν/(2ν+1)`, forcing `σ = 0` — opposite orbit bases — with `π != 0`. Grok
further checks that the same `t^1` factor for general equal `μ` is
`νμ/(2ν+1) != 0`, so the law is `μ`-uniform. That is my `e_1 = 0` at `r=2`,
derived from the printed identity by a different route, on a packet that passed
1362 checks in each mode. I treat this as one fact with two derivations.

**What nobody has said.** Write the merge pattern in solved form:

```text
p^red(eta) = eta^eps * (eta^{r*nu} - A)^mu ,     q^red(eta) = eta * (eta^{r*nu} - A).
```

The **nonzero root set of `p^red` is a single `mu_{r*nu}`-orbit.** St. 3.16 only
demands that it be a *union* of `mu_nu`-orbits; St. 3.18 assigns exactly one
existing direction per `mu_nu`-orbit. So Prop. 8.1(iv) forces the `r` arriving
directions to be precisely the `r` cosets of `mu_nu` inside `mu_{r*nu}`. The
local divisor acquires a cyclic symmetry of order `r*nu` that strictly contains
the structural `mu_nu` coming from the ramification jump. I call this
**orbit fusion**.

**Why this is not vacuous, stated carefully.** I checked the obvious kill and it
does *not* fire, and I say so rather than overclaim. `SHEET6-III.md` §1 pins
`ν_F := e_{j−1}/e_j` from the Puiseux characteristic of the branch (Not. 3.4),
*not* as the maximal `n` with `p_F ∈ η^l·C[η^n]`. So the fused pattern does not
contradict a primitivity convention, because there is none. Nor does re-reading
the local side conditions at `r*ν` break them: `dq = rν+1 ≡ 1 (mod rν)`,
`gcd(M, rν) = 1` in both witnesses (`td=8`: `M=3`, `rν = 8+6t ≡ 2 mod 3`;
`td=12`: `M=2`, `rν = 3ν` odd). The naive "hidden index doubling kills it"
reading is **false**, and I record it as a refuted sub-idea.

**What survives, and it is the valuable part.** The fusion is equivalent to a
system of equations on *transported* data, and that system is gauge-free:

> **`ORB-FUSE` transport equation.** Let `c_e` (`e = 1..r`) be the direction
> coefficients of the `r` arriving chains at the merge vertex `G` — by Not. 3.8
> these are literal Puiseux coefficients of the arriving branches at the
> exponent `π(G)`. Then a U1 merge exists only if
>
> ```text
> e_j( c_1^nu, ..., c_r^nu ) = 0   for  1 <= j <= r-1,
> ```
> equivalently `c_e^nu / c_1^nu` runs over the `r`-th roots of unity.

Three properties make this usable where earlier transport arguments were not:

1. **The `μ_ν` gauge dies.** St. 3.18 leaves each direction determined only up
   to a `ν`-th root of unity. Raising to the `ν`-th power annihilates exactly
   that ambiguity, so `c_e^ν` is a hard invariant of the arriving chain, not a
   normalization choice.
2. **The remaining `C*` gauge is harmless.** Rescaling `η ↦ λη` multiplies every
   `c_e^ν` by the same `λ^ν`, and the conditions `e_j = 0` are homogeneous.
   So the equation is invariant under the only freedom left.
3. **It is a torsion condition in `C*`.** The ratios must be *exact roots of
   unity*. This is far stronger than the "equal degrees and top coefficients"
   matching that every previous transport argument used, and it is the kind of
   condition that a single valuation, absolute value, reality, or positivity
   argument can violate outright. In particular, at `r=2` it reads
   `c_2^ν = −c_1^ν`: if the two arriving branches are related by any symmetry of
   the configuration acting trivially on `ν`-th powers, then `c_1^ν = c_2^ν` and
   the family is dead on the spot.

**Kummer reading.** `t^r − A` is a Kummer polynomial, so `ORB-FUSE` says the
`r` arrival invariants generate a `μ_r`-Kummer extension of the field generated
by `A`. The campaign already owns heavy Kummer instruments (the étale `μ_4`
torsor index theorem, the `K0` cubic-residue character certificates, the
"Kummer-field trick beats vdim" technique from the V34–V36 review). This is the
first time a Kummer object appears on the *source/book* side rather than the
endpoint side.

**What `ORB-FUSE` does not do.** It proves no kill by itself; it is a necessary
condition whose satisfiability is exactly the open question. It bounds no `td`,
constructs no `A(F)`, and says nothing about landing, `RPMC(C)`, `G2-BD`, or
JC2. It applies only to U1 merges (`r >= 2`, equal `(μ,w)`, `k = lex = 0`, no
0-arrival); case-III merges, unequal arrivals, and `k >= 1` are bounded by
Theorem A and are a different sector, and single-pole `m = 1` configurations have
no merge at all and are untouched.
