## Scope

This lane tests the terminal statement (8.1) for the terminal family
`T_{t,k}` using Opus's CONE criterion from AUDIT delta 17(cccc):

- build `I_{t,+} = <T_{t,1}, ..., T_{t,2t-1}>`;
- compute a weighted-homogeneous standard basis in
  `A_t[b4, q2_0, ..., q{t-1}_0, b3]` with weights
  `wp(1, 2, ..., t-1, t+1)`;
- certify (8.1) at a fibre when `dim(I_{t,+}) = 0`;
- if `dim(I_{t,+}) > 0`, run the Rabinowitsch test
  `1 in <I_{t,+}, 1 - z*tau_t>`.

The mandatory negative control is `t = 2`, fibre `y = 1/5`, where
`dim(I_{2,+}) = 1` but the `tau_t` criterion must still pass.

## Implementation Notes

The lane-local workspace is `box/k16cone-20260903/`.  I copied the charged
drivers there and added:

- `cone_driver.py`: sparse weighted-polynomial emitter for the charged
  coefficient-array recurrence (2.2)--(2.13), with modular, exact
  `Q[yy]/(H_t)`, and split-exact fibres.
- `summarize_cone.py`: output parser for the generated Singular logs.

The Singular source emitted by `cone_driver.py` declares the target cone ring
directly, e.g.

```text
ring r=p,(b4,q2_0,...,q{t-1}_0,b3),wp(1,2,...,t-1,t+1);
ideal Iplus=T1,...,T{2t-1};
ideal G=std(Iplus);
dim(G);
```

If `dim(G)>0`, the same source branches to a Rabinowitsch ring and tests
`1 in <Iplus,1-z*tau>`, where `tau` is the nonconstant part
`T0 - T0(0)`.  This is the requested `tau_t` criterion.  No `sat()` wrapper is
used.

For modular jobs the sparse rows were checked against
`terminal_array_recurrence.terminal_values` at deterministic residual points
before the `.sing` source was written.  The largest emitted `t=11` rows have
about 39k sparse terms, which is the main cost before Singular begins `std`.

Implementation details that matter for replay:

- `SparseRing` stores residual monomials in the exact variable order
  `(b4,q2_0,...,q{t-1}_0,b3)` and truncates by weighted degree.
- During the high solve, the truncation bound is the current pivot weight
  `1,...,2t+1`; the final terminal-row emission uses bound `4t+1`.
- The high variables `C_1,...,C_{t-1},q_{t,0},...,q_{2t,0},b2` are solved with
  the charged closed pivot diagonals from `terminal_array_recurrence.py`.
- The emitted rows use the charged sign convention
  `T[k] = -[X^k]R`, matching the point evaluator used for validation.
- Exact irreducible fibres use `ring r=(0,yy),(...),wp(...); minpoly=H_t;`.
  Split-exact controls specialize `yy` to the rational fibre first.

The modular point validations are not ideal certificates.  They only check
that the emitted sparse polynomials agree with the charged point recurrence
before a Singular ideal computation is attempted.
