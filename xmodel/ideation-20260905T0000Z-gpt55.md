## 2. Q1 - K16

**Answer.** The next K16 idea should be a norm/resultant proof over the
projectivized Eagon-Northcott incidence scheme. Do not spend the next serious
lane on another monolithic tail GB at `t=8`; use fixed `t` only to manufacture
the norm data and controls.

Typed state:

```text
Known:
  For t>=3, after clause (i), the target is exactly
    Q_t(p,beta)=a_0 beta^2+b_0 beta+c_0 != 0
  at every nonzero rank-one point of
    Sigma_t = V(u C_r + v B_r, 1<=r<t)
  over every factor of A_t.  Equivalently,
    sqrt(I_2(N)+(W_1,...,W_{t-1})) = m
  factorwise once rank-zero points are excluded.

Bounded quantity:
  the finite weighted projective scheme has degree
    d_Gamma(t) = (binom(3t+1,t-1)-binom(2t,t-1))/(t+1).
  The nonvanishing is a product of d_Gamma(t) scalar tests, not a new
  positive-dimensional search.

Wrong routes:
  LENGTH-SPLIT is conditional on finiteness and cannot prove it.
  No monomial order can give the required coprime leaders for all t.
  W_1 alone is not a chart-safe invariant.
```

The structural proof object should be

```text
N_t = Norm_{R_t/A_t}(\widehat Q_t),
widehat Q_t = a_0 v^2 + b_0 u v + c_0 u^2,
R_t = coordinate algebra of Proj Sigma_t after removing the rank-zero locus.
```

The theorem to prove is `N_t != 0` for every integer `t>=3`, factorwise in
`A_t`. This is better typed than "prove no zeros on Gamma" because it replaces
exponentially many algebraic point values by one determinant in an explicit
finite algebra. It also gives a falsifier: `N_t=0` produces an actual
rank-one point with top-row vanishing.

The reason I like this target is that all current K16 inputs point to it. The
EN complex already supplies the finite algebra and degree. FITT supplies the
eliminant identity. The coefficient recursion supplies an exact finite
presentation of `a_r,b_r,c_r,B_r,C_r`. What is missing is not another row but
the determinant of multiplication by `widehat Q_t` in the finite projective
rank-one algebra.

Cheapest test:

```text
Build R_t on the homogeneous incidence presentation
  u C_r + v B_r = 0
with one safe affine chart at a time, using the irrelevant saturation only as
a declared component operation.  For t=3,4 exact, compute the determinant of
multiplication by widehat Q_t in each chart algebra and compare with the
banked component decomposition.  Wall: <10 min, <4 GB.  Then run t=5 modulo
one good prime with the same determinant output, not primdecGTZ.  Wall target:
<30 min.
```

Interpretation:

```text
If t=3,4 determinants reproduce the known nonzero component scalars and t=5
gives a compact factored determinant, launch the all-t determinant-recursion
lane.

If the determinant exists but is huge and structureless at t=5, switch to a
flat degeneration proof of the same norm.

If any determinant is zero in a factor where existing reports say the top row
is nonzero, the ring/component map is wrong; stop and audit the incidence
construction.

If t>=7 gives zero, extract the point and test the original tail rows.  That
would be a real K16 obstruction, not a counterexample to JC2 until routed back.
```

Two implementation cautions. First, `Proj Gamma` here is a finite weighted
scheme; do not import the false intuition that a positive-degree section on a
projective curve must vanish. The affine cone is one-dimensional, so the
projective base is zero-dimensional. Second, the norm must be factorwise over
`A_t`; split indices cannot be handled by inverting a denominator that vanishes
on one factor.

I would keep direct `(8.1)` as the fallback, but it currently has less
structure. A Rabinowitsch certificate for
`tau_t in sqrt(I_{t,+})` would be ideal; the banked evidence says no closed
power/cofactor family is visible through `t<=7`, and interpolation is unsafe
because the spine depth grows with `t`. The norm proof attacks the stronger
target, but it attacks the one object the campaign has actually exposed.
