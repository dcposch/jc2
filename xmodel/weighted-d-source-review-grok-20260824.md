## 3. Independent recomputation of (4.1)--(4.8)

All algebra below is over `Z` or `Q`, truncated at `q²`. `θ(qⁿ) = 42 n qⁿ` because `q = t⁴²` and `θ = t d/dt`.

### (4.1)--(4.2)

With `U_f = 1 + α₁ q + α₂ q²` and `U_g = 1 + β₁ q + β₂ q²`,

```text
C = U_g / U_f ,     R = U_f³ / U_g²
```

give, coefficientwise,

```text
c₁ = β₁ − α₁
c₂ = β₂ − α₂ + α₁² − α₁ β₁
r₁ = 3 α₁ − 2 β₁
r₂ = 3 α₂ − 2 β₂ + 3 (α₁ − β₁)²
```

and the inverse identities `U_f = R C²`, `U_g = R C³` hold through `q²`. Differentials:

```text
δc₁ = δβ₁ − δα₁
δc₂ = δβ₂ − δα₂ + (2α₁ − β₁) δα₁ − α₁ δβ₁
δr₁ = 3 δα₁ − 2 δβ₁
δr₂ = 3 δα₂ − 2 δβ₂ + 6 (α₁ − β₁)(δα₁ − δβ₁)
    = 3 δα₂ − 2 δβ₂ + 6 c₁ δc₁
```

Both displayed forms of `δr₂` agree. Jacobian `∂(c₁,c₂,r₁,r₂)/∂(α₁,α₂,β₁,β₂)`:

```text
[[ -1,          0,    1,   0 ],
 [ 2α₁ − β₁,   -1,  −α₁,   1 ],
 [  3,          0,   −2,   0 ],
 [ 6(α₁−β₁),    3, −6(α₁−β₁), −2 ]]
```

### (4.3)--(4.4)

Because `U_f, U_g` are `η`-independent,

```text
B(Φ_full, Γ_full)
  = U_f U_g B_y
    + U_g (θ U_f) Φ_y Γ_{y,η}
    − U_f (θ U_g) Φ_{y,η} Γ_y .
```

This is spec (3.2). Substituting `U_f = R C²`, `U_g = R C³` yields

```text
B_full = R² C⁵ B_y + R C⁵ (θ R) A + R² C⁴ (θ C) D
```

with `A = Φ_y Γ_{y,η} − Φ_{y,η} Γ_y` and `D = 2 Φ_y Γ_{y,η} − 3 Φ_{y,η} Γ_y`. Direct truncated `q`-series of both sides, with dummy `η`-coefficient symbols through `q²`, agree. Spec (3.2) and (4.3) therefore agree through the registered window.

Leading forms `Φ₀ = S_M p²`, `Γ₀ = G_M p³` are `t`-independent, so `θΦ₀ = θΓ₀ = 0`. Over `Q[η]`, with `p = η⁶ − 6η³ + 6`,
