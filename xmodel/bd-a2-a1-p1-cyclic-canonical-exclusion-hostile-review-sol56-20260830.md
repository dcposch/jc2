presentation is correct, the Schur-complement calculation extends unchanged


## 2. Integral Picard presentation

The load-bearing presentation

```text
Pic(X)=<ell,F_1,F_2 | ell=m_1F_1=m_2F_2>
```

is correct in the adapted `T=M` completion.

Indeed `Pic(V)` is generated by `M`, a general fibre `ell`, and the
exceptional curves created in the two completed special fibres.  The
horizontal boundary kills `M`.  In each special fibre, successively killing
all vertical boundary components eliminates all exceptional generators but
the retained `(-1)` curve `F_i`; the total-fibre relation left behind is
exactly `ell=m_iF_i`.  There is no cross-fibre relation other than their
common class `ell`.

As a consistency check, this presentation has free rank one and torsion
`Z/gcd(m_1,m_2)`, exactly matching Miyanishi Definition 2.5:

```text
Pic(X)_tor ~= pi_1(X),  |pi_1(X)|=gcd(m_1,m_2).
```

Modulo the boundary, the integral canonical expression is

```text
K_X=-(n+2)ell+k_1F_1+k_2F_2.
```

This is stronger than the rational equation and justifies both torsion
congruences used by the producer.

For `(2,2)`, take `ell=2F_1` and `t=F_2-F_1`; then `2t=0`, so

```text
Pic(X)=Z F_1 direct-sum (Z/2)t,
K_X=(h_1+h_2-2(n+2))F_1+h_2t.
```

For `(2,4)`, take `ell=4F_2`, `t=F_1-2F_2`; again `2t=0`, so

```text
Pic(X)=Z F_2 direct-sum (Z/2)t,
K_X=(2h_1+k-4(n+2))F_2+h_1t.
```

Thus the producer's equalities and parity conditions are exact, not merely
necessary rational shadows.

## 3. Two-block Schur complement

The extension from the source's three-fibre Platonic calculation to two
fibres is valid.

Let `N_i` be the intersection matrix of the vertical boundary block in the
completed `i`th fibre after removing `m_iF_i`.  Each `N_i` is negative
definite.  The only coupling between distinct blocks is through the
horizontal section `M`, whose square is `-n`; there are no block-to-block
intersections.  Eliminating `N_i` changes the scalar entry at `M` by the
local Schur-complement contribution `alpha_i`.  Hence the inertia of the
full boundary matrix is the inertia of

```text
N_1 direct-sum N_2 direct-sum [-n+alpha_1+alpha_2].
```

An affine complement requires the boundary to support an ample divisor, so
its matrix must have a positive direction.  Because both `N_i` are negative
definite, the necessary inequality is exactly

```text
alpha_1+alpha_2>n.
```

Omitting the third block changes neither the local elimination nor the sign
criterion.  The proof needs only this necessary direction; no unproved
two-fibre sufficiency statement is being charged.

## 4. Independent check of `(2,2)`

If `K_X~0`, the integral presentation gives

```text
h_1+h_2=2(n+2),
h_2 even.
```

The first equality then makes `h_1` even.  Since `h_i=k_i>2`, both are at
least four, whence `n>=2`.  But the positive-direction inequality says

```text
n < h_1/4+h_2/4=(n+2)/2,
```

so `n<2`.  Contradiction.  Equality at `n=2` leaves Schur complement zero
and therefore supplies no positive direction.  Every inequality and parity
step is correct.

## 5. Independent check of `(2,4)`

If `K_X~0`, then

```text
h_1 even,
n=h_1/2+k/4-2.
```

Because `h_1>2`, this gives `h_1>=4`.  Integrality gives `4|k`; together with
`k>4`, this gives `k>=8`.

It remains to check the uniform local estimate

```text
alpha <= k/4-1.
```

For the one-branch rows it reduces respectively to

```text
k/16 <= k/4-1,
(k+6)/16 <= k/4-1,
```

which hold for `k>=8` (the second difference is `(3k-22)/16>0`).  For the
multi-branch row put `d=h-s>=2`, so `k=d+2s-1`.  Multiplication by the
positive denominator `16(2d-3)` gives exactly

```text
Q(d,s)=8d^2+8sd-49d-12s+55.
```

At `d=2`, `Q=4s-11>0` for `s>=3`, while

```text
Q(d+1,s)-Q(d,s)=16d+8s-41>=15.
```

The estimate is therefore strict on the entire multi-branch family.  Finally,

```text
h_1/4+alpha
 <= h_1/4+k/4-1
 <= h_1/2+k/4-2
 = n,
```

where the second inequality is equivalent to `h_1>=4`.  This contradicts
the required strict Schur inequality.  The exclusion is complete.
