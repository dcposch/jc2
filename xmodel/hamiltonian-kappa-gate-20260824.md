## 1. Signs, quotient, and exact class theorem

Put `R=C[x,y]`, `Omega=dx wedge dy`, and use

```text
[P,Q] = P_x Q_y-P_y Q_x,
X_P   = [P,-] = P_x partial_y-P_y partial_x,
D_P   = P_y partial_x-P_x partial_y = -X_P.
```

The images of `D_P` and `X_P` are equal, so either sign gives the same
additive quotient.  It is a `C[P]`-module/vector-space cokernel, not an ideal
quotient and not an `R`-algebra.

Assume `(P_x,P_y)=R`.  Choose a polynomial vector field `V` with `V(P)=1`
and define

```text
kappa(P) = [div(V)] in R/D_P(R).
```

### Proposition 1 — well-definedness

If `V'(P)=V(P)=1`, then `W=V'-V` is a syzygy of `(P_x,P_y)`.  Since this row
is unimodular, its syzygy module is generated by `(P_y,-P_x)`, so
`W=hD_P`.  Mixed partials give `div(D_P)=0`, hence

```text
div(V')-div(V) = div(hD_P) = D_P(h).
```

Thus `kappa(P)` is independent of the lift.

### Proposition 2 — exact mate equivalence

If `[P,Q]=1`, take

```text
V_Q=Q_y partial_x-Q_x partial_y.
```

Then `V_Q(P)=1` and `div(V_Q)=Q_yx-Q_xy=0`, so `kappa(P)=0`.

Conversely, if `kappa(P)=0`, write `div(V)=D_P(h)` and replace
`V` by `V-hD_P`.  The new lift still sends `P` to one and is divergence
free.  For `V=A partial_x+B partial_y`, the polynomial one-form

```text
alpha=i_V Omega=A dy-B dx
```

is then closed.  The polynomial Poincare lemma gives `alpha=dQ`; therefore
`A=Q_y`, `B=-Q_x`, and `V(P)=[P,Q]=1`.

Hence, exactly,

```text
kappa(P)=0  iff  P has a polynomial Jacobian mate.
```

This is a useful coordinate on the obstruction, but universal nonvanishing
on noncoordinates is JC2 in equivalent form.

## 4. The certified family `P_n=x+x^n y`

Fix an integer `n>=2` and put `Z=x^(n-1)y`.  Then

```text
P_x=1+nZ,                    P_y=x^n,
(1-nZ)P_x+n^2 x^(n-2)y^2 P_y=1.
```

Thus the entire family is unimodular.  A canonical lift is

```text
V_0=(1-nZ) partial_x+n^2 x^(n-2)y^2 partial_y,
V_0(P_n)=1,
div(V_0)=n(n+1)x^(n-2)y.
```

Also `P_n=x(1+x^(n-1)y)`, so its zero fiber is reducible; it is not a
coordinate.  The no-mate statement below is proved directly and does not
assume JC2.

### 4.1 Exhaustive direct slice recurrence

Give `x^i y^j` weight

```text
w_n(i,j)=i-(n-1)j.
```

For every monomial,

```text
X_P(x^i y^j)
 = j x^i y^(j-1)+(nj-i)x^(i+n-1)y^j.
```

Both outputs have weight `w_n(i,j)+(n-1)`.  Since the target `1` has weight
zero, only the input weight `1-n` can contribute.  The nonnegative-exponent
solutions of

```text
i-(n-1)j=1-n
```

are **exactly**

```text
M_k=x^(k(n-1)) y^(k+1),    k>=0.
```

This is the no-leak/exhaustiveness lemma; no other weight or monomial can
cancel the chain.  Direct calculation gives

```text
X_P(M_k)=(k+1)Z^k+(n+k)Z^(k+1).
```

If a polynomial slice existed, its relevant finite component would be
`sum_(k=0)^N c_k M_k`.  Coefficient comparison with `X_P(Q)=1` forces

```text
c_0=1,
c_m=-(n+m-1)/(m+1) c_(m-1)
   =(-1)^m (n)_m/(m+1)!.
```

Every coefficient is nonzero in characteristic zero.  The finite chain ends
with the uncancelled monomial

```text
c_N(n+N) Z^(N+1) != 0.
```

This contradiction proves:

### Scoped family theorem

For every integer `n>=2`, no polynomial `Q in C[x,y]` satisfies
`[x+x^n y,Q]=1`.  Equivalently, `kappa(P_n)!=0`.

For the required `n=3` case,

```text
P_3=x+x^3y,
w_3(i,j)=i-2j,
c_0,c_1,c_2,c_3,... = 1,-3/2,2,-5/2,...,
```

and every finite truncation has a nonzero terminal term.

For `n=2` the coefficients are `1,-1,1,-1,...`; this recovers the
Broughton no-polynomial-slice control in the direct-slice gauge.

### 4.2 Rational/formal control

The infinite series sums to the rational slice

```text

 = y * (1-(1+Z)^(1-n))/((n-1)Z),
[P_n,Q_infinity]=1.
```

After cancellation its denominator contains `(1+Z)^(n-1)`, while the
remaining numerator is nonzero at `Z=-1`; hence it is not polynomial.  At
`n=2` this is `y/(1+xy)`.  The rational survivor and its nonterminating
