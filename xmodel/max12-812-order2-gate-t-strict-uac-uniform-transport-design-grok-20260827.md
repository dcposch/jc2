## 1. Four layers that must not be conflated

Every subsequent claim is tagged with exactly one layer.

1. **Formula-level theorem.**  Polynomial or formal-series identities
   among named generating functions.  Independent of any `.poly` file.
2. **Code semantics.**  A named compiler implements those formulae
   (`source_block` versus `source_coefficients` versus `build_row`
   versus `tail_text`).  Semantic agreement of two implementations is a
   separate lemma.
3. **Frozen source custody.**  SHA-256 of a compiler, of `tails.json`,
   of a D1 chamber script.  Not the same as a serialized total row at
   grade `g`.
4. **Reviewed D1 endpoint.**  A CONFIRMED/promoted emptiness theorem on
   a named contact cell of the generic-square D1 chart.  Importing it
   into the total source requires layer 1 plus a factorization lemma,
   not a new expansion of 569 tails.

The Kummer producer mixed (1) with (4) by composing stage-zero root
matrices with `delta_D1`.  The Opus5 review and the erratum already
kill that mix: `delta_D1` annihilates `J1+J2`.  The later `a=2` and
`(2,4,>=3)` composition notes correctly switch to shifted pairs, then
reintroduce a workflow demand for “actual-total construction path
through grade `T`” as if that were a missing mathematical hypothesis.
It is not.  It is layer 3 of the *code path*, already implied by layer 1
once the compiler is pinned.

A passing discriminator replay that greps its own transcription is not
layer 1.

## 2. Mechanism 1 — the untruncated emitter as a functor

### 2.1 Formulae

Work over a field `k` of characteristic zero.  Let `sigma` be a formal
parameter.  The untruncated total source is the `k[[sigma]]`-algebra
generated by the coefficient series

```text
p(sigma)     = p0 + 2 * sum_{i>=1} sigma^i * ell_i,
Cseries(sigma) = cs + cs1*sigma + cs2*sigma^2 + ...,
Rseries(sigma) = rs + rs1*sigma + rs2*sigma^2 + ...,
Az(sigma)    = a1 + aa1*sigma + aaa1*sigma^2 + az3*sigma^3 + ...,
Ac(sigma)    = a0 + aa0*sigma + aaa0*sigma^2 + ac3*sigma^3 + ...,
Ez(sigma)    = c1 + e1*sigma + ee1*sigma^2 + ez3*sigma^3 + ...,
Ec(sigma)    = c0 + e0*sigma + ee0*sigma^2 + ec3*sigma^3 + ...,
k10(sigma)   = k + k1*sigma + k2c*sigma^2 + k10_3*sigma^3 + ...,
k6(sigma)    = k6 + k6_1*sigma + ...,
k2(sigma)    = k2 + k2_1*sigma + ...,
```

together with four target scalars `mu2, mu4, mu6, J`.  The naming of
the third `k10` jet as `k2c` is load-bearing: it is not a `k2` jet.

Set

```text
c(sigma) = sigma^2 * Cseries(sigma),
r(sigma) = ( p(sigma)^2 + sigma^2 * Rseries(sigma) ) / 4,
n3 = sigma^3 * Az,
n2 = sigma^3 * Ac,
n1 = sigma^3 * (p*Az + Ez)/2,
n0 = sigma^3 * (p*Ac + Ec)/2.                         (E1)
```

The seven ordinary coefficient primitives are the same dictionary as
the Kummer note (2.2) and as `source_block` in
`compile_t_rs0_discovery.py`:

```text
F6=2p,                      F5=2c,
F4=p^2+2r,                  F3=2p c + sigma^2 n3,
F2=c^2+2p r + sigma^2 n2,   F1=2c r + sigma^2 n1,
F0=r^2 + sigma^2 n0.                                  (E2)
```

Let `Tail_ell` be the frozen 569-monomial inverse-Faber polynomial in
`(F0,...,F6,k10,k6,k2)`, of weighted degree `12+ell` under

```text
weights = (8,7,6,5,4,3,2, 2,6,10),
```

loads linear of exponent in `{0,1}`, at most one load per monomial,
`Lambda` replaced by `sigma^2`.  Census `36+54+58+81+89+120+131=569`.
Targets:

```text
Phi_ell = Tail_ell(F, k10(sigma^4), k6(sigma^{12}), k2(sigma^{20}))
          - sigma^{2(12+ell)} * delta_ell,
(delta_1,...,delta_7) = (0, mu2, 0, mu4, 0, mu6, J/4).  (E3)
```

This is a functor of `k[[sigma]]`-algebras: any continuous substitution
of the ten input series (and the four targets) produces seven output
series `Phi_1,...,Phi_7`.  Coefficient extraction

```text
[sigma^g] : k[[sigma]][jets] --> k[jets]
```

is `k`-linear and commutes with every `k`-algebra homomorphism that
fixes `sigma` or, after truncation modulo `sigma^{N+1}`, with every
homomorphism of truncated polynomial rings.  In particular it commutes
with every contact-shift of §3.

No serialized grade-`g` file enters (E1)--(E3).  Truncation of jet
ranges is a later completeness question, not part of the functor.

### 2.2 What this does not yet say

- It does not identify `p0` with `-2 rho^2`.  The Kummer extension
  `k[p0] -> k[rho]`, `p0 |-> -2 rho^2`, is a separate finite faithfully
  flat rank-two map, ramified at `rho=0`.  Allocations in §4 use it
  only on `D(rho)`.
- It does not assert that V20/V22 `build_row` literally calls
  `tail_text`.  Opus5 already recorded that they do not.  Index and
  load conventions agree; that is layer 2.
- Frozen actual-total grade-15 rows being `rho`-even is a property of
  one exporter, used only if one insists on comparing against those
  particular `.poly` bytes.  The functor itself lives over `k[p0]`.

### 2.3 Desk check

Substituting the parameterized map of §3 into (E2), truncated at
`sigma^{12}`, gives identical `F0,...,F6` on the total side and the D1
`source_coefficients` side for the contacts

```text
(2,3,2), (2,4,3), (2,5,3), (5,6,5), (1,4,2), (8,11,8).
```

That is layer 1 for the primitives.  The 569-tail functoriality is the
same substitution applied to (E3) and does not require expanding a
single tail monomial in `sigma`.

## 3. Mechanism 2 — parameterized finite-jet map

### 3.1 Strict unique-`AC` domain

On the normalized integral unit-load horizontal chart,

```text
q = ord(k10) = 0,   a = ord(A) >= 1,   c = ord(C) >= 3,
r = ord(R) >= 2,    d = c-a,           s = r-a.
```

The five unit-load lower-hull weights

```text
AC=a+c,   C2=2c,   R3=3r,   RC=1+r+c,   A2=4+2a
```

give unique minimality of `AC` if and only if

```text
1 <= d <= 3,   s >= 0,   a + 3s > d.                   (U)
```

The candidate’s restriction `d in {1,2,3}` is exactly this cell.
Equality faces `d=0` (`AC=C2`), `d=4` (`AC=A2`), `s=-1` (`AC=RC`),
and `a+3s=d` (`AC=R3`) are excluded.  The two omitted `s=0` points
with `a<=9` are

```text
(a,d,r)=(2,2,2),   (3,3,3),
```

both `AC=R3`.  They are not gaps.

Least integral `s` with `r=a+s>=2` and (U):

```text
d=1:  s_min=0 for a>=2   (c>=3 forces a>=2);
d=2:  s_min=1 for a=1,2;  s_min=0 for a>=3;
d=3:  s_min=1 for a=1,2,3; s_min=0 for a>=4.
```

Independent census of `1<=a<=9` produces eight `d=1` tails, eighteen
`d=2,3` tails, and no omitted strict point.

### 3.2 D1 source dictionary, and the factors `2` and `4`

The frozen D1 compiler `compile_r1_d1_ac.py` (`e024a13d…`) encodes
`K=L^2+sigma^2 R`, `D=LA+C` by

```text
kc = sigma^2 * rz,                 kr = P^2/4 + sigma^2 * rc,
n3 = sigma^3 * az,                 n2 = sigma^3 * ac,
n1 = sigma^3 * (P*az/2 + cz),      n0 = sigma^3 * (P*ac/2 + cc),
```

then the same (E2).  Direct polynomial `R = R_z z + R_c` and
`C = C_z z + C_c` are converted to the older generating-function chart
by the factors `4` and `2`:

```text
Cseries  = R_z,                 Rseries = 4 * R_c,
Ez       = 2 * C_z,             Ec      = 2 * C_c,
Az       = A_z,                 Ac      = A_c.          (F24)
```

These are forced by matching (E1) to `source_coefficients`.  They are
not cosmetic.  Desk mutation:

```text
rs-factor 4 -> 1 : first F-mismatch (F0, grade 4);
ez-factor 2 -> 1 : first F-mismatch (F0, grade 8);
drop 2*sigma*ell1: first F-mismatch (F0, grade 1).
```

Visibility of those mismatches *in the seven Phi rows* is later, and
chamber-dependent (Opus5: factor `4` and the moving term are invisible
in D1AC rows at grade 15).  A control that only compares handwritten
`F`-strings, as the Kummer replay did, is not a row-level control.

### 3.3 The map `delta_{a,c,r}`

Fix integers `a,c,r` in the cell (U) and truncation depths
`m_P, m_A, m_C, m_R, m_{k10}, m_{k6}, m_{k2}` (determined in §3.6).
Let `D(a,c,r)` be the D1 polynomial ring on

```text
p; ell_1..ell_{m_P};
azD_0..azD_{m_A}, acD_0..acD_{m_A};
czD_0..czD_{m_C}, ccD_0..ccD_{m_C};
b1_0..b1_{m_R},   b0_0..b0_{m_R};
k0, k10_1..; k60, k6_1..; k20, k2_1..; mu2,mu4,mu6,J.
```

The finite-jet map

```text
delta_{a,c,r} : U_{tot} --> D(a,c,r)
```

is the unique `k[sigma]`-algebra homomorphism with

```text
p0 |-> p,
ell_i |-> ell_i          (1 <= i <= m_P),   ell_i |-> 0 otherwise;

Cseries_i |-> b1_{i-r}   if r <= i <= r+m_R, else 0;
Rseries_i |-> 4*b0_{i-r} if r <= i <= r+m_R, else 0;

Az_i |-> azD_{i-a}       if a <= i <= a+m_A, else 0;
Ac_i |-> acD_{i-a}       if a <= i <= a+m_A, else 0;

Ez_i |-> 2*czD_{i-c}     if c <= i <= c+m_C, else 0;
Ec_i |-> 2*ccD_{i-c}     if c <= i <= c+m_C, else 0;

k    |-> k0,             k10-jets as needed, else 0;
k6   |-> k60,            ... ;
k2   |-> k20,            ... ;
targets fixed.                                      (D)
```

Lower contact jets are killed because an exact-order arc already has
them zero, not because the infinite series is being replaced by a
quotient of the whole formal disc.  Later jets are killed only after a
support bound shows they cannot enter grades `<= T`.

Special cases already written in the charged notes:

```text
(a,c,r)=(2,3,>=2):  (D) recovers Kummer (6.1) / CF-D1-A2 (4.2),
                    with theta absorbed into nonzero leading forms
                    or set to 1, eta tracking extra R-order;
(a,c,r)=(2,4,>=3):  (D) recovers a2d2 (4.3)--(4.4).
```

On a DVR arc one may further set `eta = 0` when `ord(R)>r_floor`; that
is a closed tail, not an inversion of leading `R`.

### 3.4 Moving connection and Hensel root

```text
P(sigma) = p + 2 * sum_{i=1}^{m_P} sigma^i * ell_i.
```

On `D(rho)` after Kummer, `p = -2 rho^2` and `L = z^2 + P/2` is
squarefree at `sigma=0`.  The two Hensel roots of
`lambda(sigma)^2 + P(sigma)/2 = 0` through order `m_P` are

```text
lambda_0 = epsilon * rho,          epsilon in {+1,-1},
lambda_1 = - ell_1 / (2 lambda_0),
lambda_j = - ( ell_j + sum_{i=1}^{j-1} lambda_i lambda_{j-i} )
           / (2 lambda_0).                           (H)
```

Equivalently the ideal

```text
H_root = ( p+2*lam^2,
           2*lam*rho_1 + ell_1,
           rho_1^2 + 2*lam*rho_2 + ell_2,
           ... through order m_P )
```

used by the `B22` compiler.  The two choices of `epsilon` are the two
allocations of §4; the deck involution `rho |-> -rho` exchanges them.
This is unavailable at `rho=0`.

### 3.5 Correction of `T=10+a+c+d`

Write the four inverse-Faber summands

```text
f^{3/2} + sigma^4 k10 f^{5/4} + sigma^{12} k6 f^{3/4} + sigma^{20} k2 f^{1/4}
```

with `f = K^2 + sigma^5 D`, `K = L^2 + sigma^2 R`, `D = L A + C`, and

```text
X = 2 sigma^2 R/L^2 + sigma^4 R^2/L^4 + sigma^5 A/L^3 + sigma^5 C/L^4.
```

The first polar grades of the families that actually occur on unique-`AC`
are

```text
AC/L         :  G     = 10 + a + c = 10 + 2a + d,
C^2/L^2      :  T_C2  = 10 + 2c     = 10 + a + c + d = 10 + 2a + 2d,
RA^2/L^2     :          12 + r + 2a,
A^3/L^3      :          15 + 3a,
k10 R^3/L    :          10 + 3r,
k10 R C/L    :          11 + r + c,
k10 R^2 A/L^2:          13 + 2r + a,
k10 A^2/L    :          14 + 2a,
k6 C/L       :          17 + c,
k2 R/L       :          22 + r,
mu2, mu4, mu6, J/4 :    28, 32, 36, 38.              (P)
```

So the candidate formula is correct as **the first `C^2` grade**, and
incorrect as a universal transport ceiling.

### 3.6 Finite support / jet maxima

A polar family first arriving at grade `g_S` and carrying stem `S`
requires jet `S_j` through grade `T` if and only if `j <= T - g_S`.
Hence, on a chamber with terminal `T_*` and first polar grade `g_0`,

```text
m_P  = T_* - g_0,          # moving p; equivalently remainder of the
                           # earliest in-window polar family
m_A  = T_* - g_{AC},       # AC is the first A-bearing polar on unique-AC
                           # except when k6 C precedes AC
m_C  = T_* - min(g_{AC}, g_{k6 C} if that grade <= T_*),
m_R  = T_* - g_{k10 RC} or 0 if that family is out of window
                           # closed tails often have m_R=0
m_{k6} = T_* - (17+c) if 17+c <= T_* else -infinity (no k6 jet),
```

and likewise for `k10, k2, mu*`.  This is the same arithmetic the
`a>=10` review used to get

```text
A_7, C_10, R_6, k10_6, k6_10, k2_6, p_10, mu2_10, mu4_6, mu6_2
```

at `T_*=38`, `g_0=28`.  It is not an expansion of 569 tails.

Naive `F`-valuation without cancellation (e.g. `F0*F3` producing an
isolated `A` at grade `5+a`) overpredicts jets.  Those terms cancel in
`Tail_ell`, which is why D1AC is divisible by `sigma^{15}` and why the
polar table, not raw `F`-valuation, is the correct bound.  Completeness
is therefore inherited from each chamber’s reviewed support inventory,
not re-proved by a single formula.

`UAC-FID` through grade `T_*` is independent of every discarded later
jet.  It is not the false claim that the full infinite series factors
through the quotient that sets those jets to zero.

## 4. Mechanism 3 — shifted leading pairs, not `J1,J2`

Stage-zero matrices of the Kummer note (5.1),

```text
R± = rs/4 ± rho*cs,     det = -rho/2,
C± = (c0 ± rho*c1)/2,   det = -rho/2,
A± = a0 ± rho*a1,       det = -2 rho,
```

are invertible on `D(rho)` and degenerate at `rho=0`.  Under (D), for
every unique-`AC` contact one has `a>=1`, `c>=3`, `r>=2`, so

```text
delta(rs)=delta(cs)=delta(c0)=delta(c1)=delta(a0)=delta(a1)=0.
```

The composed stage-zero chart is the zero map.  The erratum is correct
and applies to the whole fan, not only to D1AC.

The leading nonzero pairs are the same matrices on the jets of index
`r`, `c`, `a`:

```text
R0± = Rseries_r / 4  ± rho * Cseries_r,
C0± = (Ec_c ± rho * Ez_c)/2,
A0± = Ac_a ± rho * Az_a.                              (S)
```

After (D) and (F24),

```text
R0+ = b0 + rho*b1 = R(rho),     R0- = R(-rho),
C0+ = ccD_0 + rho*czD_0 = C(rho),
A0+ = acD_0 + rho*azD_0 = A(rho).
```

Desk check with dummy nonzero values confirms the identifications and
the determinants of (S), which are again `-rho/2, -rho/2, -2 rho`.

On `D(rho)`, `L = z^2 - rho^2` is squarefree.  The first unique-`AC`
primitive is `(3/4) AC/L` at grade `G` (or a `k6`-shift of it, §6).
Exact contact makes leading `A0, C0` nonzero linear, so `L | A0 C0`
gives exactly two allocations

```text
Alloc_+ : A0 = au (z - rho),   C0 = cv (z + rho),
Alloc_- : A0 = au (z + rho),   C0 = cv (z - rho).     (A)
```

In shifted coordinates: `Alloc_+` is `A0+ = 0` and `C0- = 0`;
`Alloc_-` is `A0- = 0` and `C0+ = 0`.  The deck involution exchanges
them.  Neither allocation is a statement about the vanished stage-zero
generators of `J1` or `J2`.

This uses the generic-square first-normal form (A, C, R linear in `z`)
and `D(rho)`.  It is not a ramified-fibre chart.

## 5. Mechanism 4 — endpoint provenance

A uniform source identity is useless if the D1 theorem being composed
is not a theorem about the image of (E3).

### 5.1 What “about the image” means

The D1 ring of a chamber is, by (D) and `UAC-FID`, the finite-jet
image of the total emitter through `T_*`.  An emptiness theorem
composes if and only if its obstruction is an identity in the seven
literal `Phi_ell` (or a localization/saturation thereof), possibly
after the allocations (A) and the Hensel lift (H).

Analytic generating functions are allowed as *derivation devices* if
and only if a reviewed `ROW_IDENTITIES` (or an equivalent
Laurent-to-Faber bridge) identifies them with those `Phi_ell` through
`T_*`.  They are not allowed as extra equations the total arc is not
known to satisfy.

Direction: a total DVR arc of the exact contact factors through
`delta_{a,c,r}` at grades `<= T_*` (support, §3.6).  Composing with a
D1 emptiness theorem therefore kills the total arc.  The opposite
scheme-morphism direction (total empty `=>` D1 empty), which is what
the raw ring map `delta` gives without factorization, is the terminal-
receiver implication of the Kummer erratum and is not used here.

Coverage warning, already correctly stated in the `a=2` composition:
emptiness of one contact client plus deck equivariance is not a cover
of `D(rho)`.  The countermodel `q: k[rho,u] -> k[rho,u]/(u)` sending
`(u-1)` to `(1)` remains the right no-go.

### 6.1 Two real inductions, neither covering the fan
