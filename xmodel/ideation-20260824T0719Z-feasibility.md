## 3. Root H — exact class first, software second

### 3.1 Exact mathematical core

Let `R=C[x,y]`, let `(P_x,P_y)=R`, choose a polynomial vector field `V`
with `V(P)=1`, and put

```text
D_P = P_y partial_x - P_x partial_y,
kappa(P) = [div(V)] in R / D_P(R).
```

The launch packet should require a short paper proof of both statements
before any experiment:

1. `kappa(P)` is independent of `V`. If `V'-V` annihilates `P`, the
   unimodular syzygy module is generated by `D_P`; writing
   `V'-V=hD_P` changes divergence by `D_P(h)`.
2. `kappa(P)=0` if and only if there is a polynomial `Q` with
   `[P,Q]=1`. Vanishing permits a divergence-free lift of `partial/partial P`;
   polynomial de Rham exactness makes that lift Hamiltonian. The converse is
   immediate from a Hamiltonian lift.

This equivalence is exact but, by itself, is a reformulation of the
first-coordinate problem. The research content begins only when either:

- a named filtration proves nonmembership in `D_P(R)` for an independently
  specified class of `P`; or
- a Gauss--Manin/atypical-end functional on the cokernel is defined without
  assuming a mate `Q` and without collapsing to an ordinary residue of an
  exact differential.

### 3.2 Inputs and controls

### 3.3 Concrete local software architecture

Use a small deterministic exact package, not a general sparse search:

```text
hamiltonian/

  operators.py    d/dx, d/dy, divergence, D_P, Jacobian
  bezout.py       imports or verifies a supplied Bezout certificate
```

Each run emits a machine-readable certificate containing `P`, the Bezout

## 4. Root P — universal-pencil gate with a typing stop first

The proposed object has the highest global upside, but it is less
implementation-ready than the blind reports suggest. Before GRR or any
boundary calculation, resolve two basic typing hazards.

### 4.1 Hazard 1: a defect function need not be a divisor

For `H_[a:b]=aP+bQ`, an infinity-vanishing-cycle number is naturally a
constructible function of `[a:b]`. If it is positive on a Zariski-open set,
placing its value as the coefficient of every direction does **not** define
a finite-support divisor on `P^1`. Subtracting the generic value gives a
jumping divisor, but `degree zero` for that divisor would not imply zero
generic defect.

The first deliverable is therefore one of:

- `GENERIC-ZERO`: prove the generic defect is zero under the Keller
  hypotheses, so the exceptional values define a finite effective divisor;
- `JUMP-ONLY`: only the jumps form a divisor, in which case the proposed
  endpoint is insufficient and this version stops; or
- `NOT-CONSTRUCTIBLE/TYPE-FAIL`: the chosen defect does not descend
  functorially to the dual pencil.

### 4.2 Hazard 2: controls live at different levels

Identity, triangular, two-shear, and Hénon maps are full Keller-pair
controls and must give zero total defect. Broughton's
`x+x^2y` has no polynomial mate, so it can test the **single-polynomial
local defect definition**, but it cannot test the full `V_F` degree formula.
The implementation must separate these two interfaces rather than silently
feed Broughton into a pair-level construction.

### 4.3 Exact first gate

After those points are typed:

1. define the relative vanishing-cycle/characteristic-cycle object on one
   common graph resolution of the universal linear pencil;
2. prove invariance under an additional boundary blowup;
3. prove coefficient effectivity and finite support;
4. derive only the first pushforward/degree formula;
5. reduce every term against the existing pure-boundary Jacobian and no-log
   identities;
6. test the four full automorphism controls and Broughton's local defect.

The boundary-different identity may be used as a comparison line. If it
merely reproduces the canonical-divisor/different term and yields no
principal boundary relation, record `DUPLICATE` and do not open a separate
normalization root.

### 4.4 Software and cost

This is principally a paper root. A small exact checker may represent a

- Typing and generic-support gate: 2–4 hours.

Immediate stops are `JUMP-ONLY`, presentation dependence, an automorphism

## 5. Root S — bounded p=109 support graph

### 5.1 Why this is the counterexample root

The seed

```text

```

has exact Jacobian one, Artin--Schreier degree 109, and the marked collision
`(0,0),(1,0) -> (0,0)`. Unlike the stopped degree-three K3 compiler, its
degree is not ruled out by the campaign's characteristic-zero degree bounds.
Unlike another Witt level, the first gate asks whether exact exponent
interactions admit a finite feedback cycle rather than an escaping support
ray.

The graph is still only a support necessary-condition instrument. A cycle is
not a lift, a modular lift is not a characteristic-zero point, and neither is
a counterexample.

### 5.2 Phase S0: specification lock

No code should run until one frozen manifest states:

- prime `109` and the exact seed;
- whether correction vertices belong to `P`, `Q`, or the residual;
- the exact monomial-bracket rule
  `(a,b),(c,d) -> (a+c-1,b+d-1)` with coefficient `ad-bc`;
- the support grammar from which a cancelling correction may be generated;
- at most eight correction monomials total;
- collision equations and coordinate normalization;
- the tangent automorphism/gauge moves being quotiented;
- what constitutes an escaping edge, a closed correction state, and a
  strongly connected core.

If the allowed grammar is an arbitrary rectangle, or if exhaustiveness
depends on an unstated degree cutoff, return `NO-FROZEN-GRAMMAR` and stop.
The number eight is a registered experiment cap, not a conjectural
completeness bound.

### 5.3 Concrete software architecture

Use two independent local implementations with a shared certificate schema:

```text
as109_support/
  manifest.json       hashed seed, grammar, gauge, cap, collision
  algebra.py          exact exponent/bracket and F_109 coefficient rules
  enumerate_dfs.py    canonical-state exhaustive DFS with memoization

  heights.py          exact rational/integer separating-height search
  certificate.py      HEIGHT-CERT or minimal CYCLE serialization
  verify.py           independent certificate and collision/gauge replay
  controls.py         all-Witt escaping ray, gauge cycle, toy finite cycle
```

The two enumerators must not share transition-generation code. The verifier
may share only the manifest schema. States are canonicalized after the

For `HEIGHT-CERT`, emit an integral weight vector and every strict linear

cycle that fails coefficient compatibility is `SUPPORT-ONLY`, not a
