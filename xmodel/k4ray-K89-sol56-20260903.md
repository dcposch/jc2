## Reduction beyond the top-band pin

### Formal quotient recurrence

Write total-degree bands

```text
h_i = [h]_(K-i),        h_0=H,
p_i = [beta]_(b-i),     p_0=P,
S_n = sum_(a+b=n) h_a*h_b,
T_n = sum_(a+b+c=n) p_a*p_b*p_c.
```

For the formal quotient `q=beta^3/h^2`, define its bands without ever dividing
by `H`:

```text
N_n = T_n - sum_(i=1..n) S_i*q_(n-i),
N_n = H^2*q_n.                                      (REC_n)
```

Let `r=K-6`. For K=8,9, degree comparison in the exact cubic identity shows
that all terms except `beta^3-(3rho+lambda)h^2` are below the terminal degree
`K+6`. The necessary bands are therefore

```text
q_i = 3*rho_(r-i)          for 0 <= i < r,
q_r = 3*rho_0 + lambda     (one free scalar),
q_i = 0                    for r < i < 2r,
N_(2r) = +Theta.
```

The terminal sign is positive and there is no scale factor when `p_i` are beta
bands. The construction uses polynomial coefficient identities throughout;
there is no `sat()` call and no division by an `x,y` form.
