## 4. New avenue

**Wronskian dictionary: the Jacobian writes the `f`-tree as
a function of the `g`-tree; FILTER-INVERSION's free joint
tree is the wrong moduli space.**

Not a 0741Z card, not a raw 2-variable expansion of `[f,g]=1`
in the local coordinates of `D_1` (the running flagship's
charge: right *lane*, wrong *moduli*). Reduce that identity
to a 1-variable order along each `g`-branch.

### 4.1 The identity

Let `f,g ∈ C[x,y]` be monic in `y`. Along a Puiseux branch
`y = tau(x)` of `g = 0`,

```text
    d/dx  f(x, tau(x))  =  [f,g] / g_y(x, tau) .
```

This is implicit differentiation, not a new theorem:
`g(x,tau) ≡ 0 ⇒ tau' = −g_x/g_y`, hence
`f_x + f_y tau' = (f_x g_y − f_y g_x)/g_y`. For a Keller pair
`[f,g] = 1` (or a unit; the monic-gauge automorphism control
`(y, x+y^k)` has Jacobian `−1`).

In `t = x^{-1}`, `d/dx = −t^2 d/dt`. If
`ord_t f(tau) = lambda` with `lambda ≠ 0` and the leading
term not killed by `d/dt`,

```text
    ord_t (d/dx f(tau))  =  lambda + 1 .
```

The right-hand side has order `ord_t J − ord_t g_y(tau)`. For
`J ∈ C^*` this is `−ord_t g_y(tau)`, and
`g_y(tau_i) = prod_{j≠i}(tau_i − tau_j)` (monic), so

```text
    − lambda_f^{(i)}  =  1 + sum_{j≠i} ord_t(tau_i − tau_j)     (J unit, lambda ≠ 0).
```

The right-hand side is a functional of the *`g`-tree alone*.
The `f`-roots are not a second free ultrametric tree. They
are determined, order-by-order, by the mutual distances of
the `g`-roots plus the unit Jacobian.

FRONTIER-N writes `N` on the tree of `f·g`. The dictionary
says that on a Jacobian pair the `f` factor of that tree is
not free. FILTER-INVERSION's "proportional configuration
that drives `N|_{D_1} → 0`" is a configuration of a free
*pair* of trees. It may be illegal for a single polynomial
and its Jacobian mate. That is a different statement from
"unknown structure can only lower `N`."
