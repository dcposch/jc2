## 1. MF-EXACT

Take a generic target coordinate pair `(u,v)` and a generic affine line
`L={u=gamma}`. Equivalently

```text
C_L = F^{-1}(L) = { alpha P + beta Q = gamma },
```

with `(alpha,beta)` and `gamma` outside the usual finite bad set. This is the
generic member of the affine pencil generated by `P,Q`.

Since `Jac F` is a nonzero constant, `dF` is an isomorphism everywhere. For
generic nonzero `du`, `d(u o F)=du o dF` never vanishes. Thus `C_L` is smooth
and reduced. The degree of `C_L` as an affine plane curve is
`D_F=max(deg P,deg Q)` after choosing `(alpha,beta)` so that the top terms do
not cancel.

The restriction over `L\A_F` is the degree-`N` etale cover

```text
C_L \ F^{-1}(A_F) -> L \ A_F .
```

Zariski's generic-line theorem gives the surjection used in DG:317-320 and
DR:216-219, so the restricted cover has transitive monodromy. Therefore the
open curve is connected, and the smooth curve `C_L` is connected and
irreducible. Let `X_L` be the smooth projective model and let
`pi:X_L -> P^1` be the compactified map induced by `v`.

There is no affine ramification: at every affine point of `C_L`, `F` identifies
the tangent line to `C_L` with the tangent line to `L`. Finite branch values can
therefore occur only where the cover is nonproper, namely the `n` transverse
points of `L cap A_F`. The generic meridian cycle type is the one already used
for MERIDIAN-FLOOR:

```text
1^a * product_l mu_l^{s_l},      W=N-a=sum_l s_l mu_l,      S=sum_l s_l.
```

This is MI:82-88 and DR:221-228. Over each of the `n` points of `L cap A_F`,
the compactified fibre has `a` affine unramified points and `S` source-infinity
places with ramification indices `mu_l` repeated `s_l` times. The ramification
contribution is therefore

```text
sum_l s_l(mu_l-1) = W-S
```

per point. Over the target point `infty in P^1`, let `theta_inf` be the number
of points of `X_L` in that fibre. The contribution over target infinity is
`N-theta_inf`. Riemann-Hurwitz gives

```text
2g_L - 2 = -2N + n(W-S) + (N-theta_inf),
```

hence

```text
MF-EXACT:        n(W-S) = N - 2 + 2g_L + theta_inf.
```

The total number of source-infinity places of the plane curve `C_L` is

```text
theta_L = nS + theta_inf:
```

`nS` are over the finite points `L cap A_F`, and `theta_inf` are over target
infinity. The Euler characteristic form is `chi(C_L)=N-nW`.

The banked meridian floor follows from `g_L>=0` and `theta_inf>=1`. The exact
defect is `2g_L+theta_inf-1`.

Non-Keller control: for `F_m(x,y)=(x,y^m)`, take `L={x=c}`. Then
`C_L ~= A^1`, `pi(y)=y^m`, `N=m`, branch curve `B={v=0}` replaces `A_F`,
`n_B=1`, `W=m`, `S=1`, `g_L=0`, `theta_inf=1`. The identity reads
`m-1=m-2+1`. This is not a Keller test; it is a clean Riemann-Hurwitz
bookkeeping control showing the finite branch and infinity terms are placed
correctly.

Promoted `N=4` control: MI:N4-PIN gives `N=4`, `W=2`, `S=1`, generic cycle
type `(2,1,1)`, cusp local type `(3,1)`, and double-point type `(2,2)` at

## 2. Meridional Rank And The Group Audit

generation number. A generic line sees `n=#(L cap A_F)` meridians, and these
generate `G=pi_1(C^2\A_F)`. Define `mrk(G)` to be the least number of
conjugates of a meridian needed to generate `G`. Then

```text
mrk(G) <= n.
```

The block-merge argument lower-bounds `mrk(G)` by
`ceil((N-1)/(W-S))`; only after that inequality do we get a lower bound on
`n`. This is a theorem about the stated apparatus. It is not, as written at
MFS:82-83, a theorem that no future group-theoretic idea could ever interact
with geometry to upper-bound `n`. The safe replacement is:

```text
Any argument whose only bridge to the curve degree is mrk(G)<=n can yield only
a lower bound on n.
```

## 3. LOC-MULT

Let `P in Sing(A_F)`, let `Loc_P=pi_1(B_P\A_F)` for a sufficiently small Milnor
ball, and let `T_P` be the number of orbits of `rho(Loc_P)` on the `N` sheets.
For a covering of the punctured ball, these orbits are exactly the connected
components of the pullback.

The local complement of a plane curve germ of multiplicity `m=mult_P(A_F)` is
generated by `m` strand meridians after a generic projection. Under H2 these
are conjugate in the global complement to the generic meridian, whose
reflection length is `W-S`. Thus local block merge gives

```text
N - T_P <= mult_P(A_F) * (W-S).                         (1)
```

Now compare `T_P` with the fibre law. MI:222-246 gives

```text
N - a_P = r_P W + K_P,
```

where `r_P` is the number of normalization branches over `P`, `a_P` is the
number of affine preimages of `P`, and `K_P>=0`. MI:251-256 gives the global
charge identity `sum K_P=a-1`.

The `a_P` affine preimages give `a_P` one-sheet local components because `F`
is etale. The escaping components are indexed by points of
`h_l^{-1}(eta^{-1}(P))`; for each of the `r_P` branches and each dicritical
`l`, there are at most `s_l` such points. Hence

```text
T_P - a_P <= r_P S.                                      (2)
```

Combining (1), (2), and `N-a_P=r_P W+K_P`,

```text
N-T_P >= N-a_P-r_P S = r_P(W-S)+K_P,
```

so

```text
LOC-MULT:     mult_P(A_F) >= r_P + ceil(K_P/(W-S)).
```

Also `mult_P>=2` for singular points. This proves MFS:192-218.

Bezout step: since `A_F` is irreducible and singular, a line through two
distinct singular points is not a component of `A_F`. Therefore
`mult_P+mult_Q<=n`. The local delta inequality
`delta_P>=mult_P(mult_P-1)/2`, summed over affine singularities and combined
with DR:109-126 (`delta_aff<=p_a(n)`), gives the delta leg of MFS:227-237.

`N=4` control: MI:585-592 has a cusp with `(r,K,a_P)=(1,1,1)` and double
points with `(r,K,a_P)=(2,0,0)`. Since `W-S=1`, LOC-MULT gives multiplicities

is the advertised recovery of the Chau-lane B3 value. It uses N4-PIN only as
input data; LOC-MULT is not smuggling in the old degree bound.

## 7. Sharp-Chau

`D_F=max(deg P,deg Q)`. A degree-`D_F` plane curve has at most `D_F` places at

```text

```

Hence

```text

n <= (D_F-theta_inf)/S <= (D_F-1)/S,

```

generic target coordinate `(u,v)`, no cancellation in `deg(u o F)=D_F`,
generic line `L={u=gamma}`, generic meridian type from MI:82-88, and `S>=1`.
It sharpens the Chau cap `n<=D_F`, especially when `S>1`, but it does not give
the missing upper half of `OPEN[N-VS-MAPDEG]`.
