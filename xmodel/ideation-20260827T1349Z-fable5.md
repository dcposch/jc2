## 3. Genuinely new mechanism and new cross-avenue connections

### 3.1 New mechanism: arithmetic square-class (Kummer/mu_2) rigidity on the promoted `8_28` carrier identities

The promoted R2 theorem (`0f8f3833…`/review `b271a295…`) says: at each
simple root `c` of `H=X^8-1`, the first weight-22 constant carrier is
factorwise either

```text
branch 1:  6*H'(c)*V8(c)*U14(c) = lambda        (V8(c) != 0)
branch 2:  (9/2)*H'(c)*U11(c)^2 = lambda        (V8(c) = 0)
```

with `lambda` the Jacobian constant (promoted statements normalize
`lambda=1`).  Since `H'(c)=8c^7=8/c` on `c^8=1`, branch 2 is exactly

```text
U11(c)^2 = lambda*c/36 .
```

**Observation (proposed theorem R4).**  The R1/R2 normalization chain is
rational over the coefficient field: the chart maps are monomial
(`x=t^3X`, `y=t^-1`, `g=t^-12 G` per the R1 review) and the Morse step is a
completion of the square with `u = H mod t` (`verify_r2.py`, metadata line
"parametric formal Morse normalization F=u^2+U(t), with u=H mod t"), so no
root extraction occurs and, for a realization defined over `k`, the
root-local data `V8(c), U11(c), U14(c)` lie in the residue field `k(c)`.
Then branch 2 at `c` **requires `lambda*c` to be a square in `k(c)`**
(36 = 6^2 is absorbed).  Elementary consequences:

- `k ⊆ R`: at the real root `c ∈ {±1}` with `lambda*c < 0`, branch 2 is
  impossible; that root is forced to branch 1, so `V8` and `U14` are nonzero
  there with `V8(c)*U14(c) = lambda*c/48`.
- `k = Q`, any `lambda ∈ Q^*`:
  - factor `(X^4+1)` (roots `zeta_8`): branch 2 is impossible for **every**
    rational `lambda`.  If `mu^2 = lambda*zeta_8` with `mu ∈ Q(zeta_8)`,
    then `zeta_16 ∈ Q(zeta_8, sqrt(lambda))`; but `Q(zeta_8)=Q(i,sqrt2)`
    already contains `sqrt(m)` for `m ∈ {-1,2,-2}` and any other squarefree
    `m` introduces odd ramification, while `Q(zeta_16)/Q(zeta_8)` is
    ramified only over 2; and `zeta_8` itself is not a square in
    `Q(zeta_8)` because `[Q(zeta_16):Q(zeta_8)]=2`.  So the four primitive
    8th roots always carry branch 1.
  - factors `(X-1)`, `(X+1)`, `(X^2+1)`: branch 2 requires respectively
    `lambda ∈ (Q^*)^2`, `-lambda ∈ (Q^*)^2`, `lambda ∈ ±2·(Q^*)^2`
    (the last from `(a+bi)^2 = lambda*i ⟺ a^2=b^2, 2ab=lambda`).  These
    square classes `{1,-1,2,-2}·(Q^*)^2` are pairwise distinct, so **at
    most one of the three small factors can carry branch 2**, and for
    `lambda ∉ ±1·(Q^*)^2 ∪ ±2·(Q^*)^2` none can.
  - with the reviewed normalization `lambda=1`: branch 2 is impossible at
    every root of `(X+1)(X^2+1)(X^4+1)`; only `(X-1)` may carry it.  In
    particular R2's own illustrative split `V8 = X^4+1` (branch 2 on the
    whole factor `X^4+1`) can never be realized over `Q`.

So for Q-defined (and largely for R-defined) realizations of the `8_28`
Keller face, branch 1 with the exact product constraint
`V8*U14 ≡ lambda*X/48` on the forced factors is not optional — precisely
the object R1 already showed is *not* a raw row (`M(X/48)=1+(13/12)H`) and
that the compiler successor must therefore synthesize from cleanup mixing.

**Scope firewall (as important as the theorem).**  Over `Q̄`/`C` there is no
constraint: every residue is a square.  Hence (i) an exact-Q compiler run
that fails only on branch-2 patterns is *Galois-forced* and must never be
promoted as evidence against the complex family; (ii) conversely a
Q-rational guided search may impose branch 1 on ≥3 of 4 factors a priori.
A minimal counterexample need only exist over `Q̄`, so R4 is a rigidity and
interpretation firewall, not a family exclusion.
