# Significant-news ideation: AS terminal survivors and the portfolio

**Trigger.**  Three exact `D=7`, `p=3` filtered states pass every encoded
predecessor/Q9/Q8/Q7 row and all 46 displayed `/243` rows in degrees 12--9.
The very next source-honesty check separates them: the displayed base-303 and
base-513 models fail the final G8 row after Q7 restoration, whereas base 519
passes G8 but its licensed Q6/H7,J7 plus divided-high affine system has rank
pair `(16,17)`.  Thus the news is not “an AS lift”; it is an unusually sharp
example of terminal survival followed by a small closure obstruction.

I rescanned the 46-avenue portfolio with this distinction in view.  It does
not reorder the maximum-12, TD6, `(6,9)` common-cubic/Davenport--Stothers,
or global infinity lanes merely because an `F3` state survived.  It does
change which reusable invariant and software should be built first.

## Bet 1: restoration curvature / automatic closure adjoint

Later restoration variables can preserve their own triangular row while
changing an earlier row after substitution.  The base-303/base-513 final-G8
defect is exactly this phenomenon; base 519 shows that even when the first
commutator vanishes, the next Schur-complement/left-null class can be nonzero.
Package this as a **restoration-curvature complex**:

```text
accepted triangular rows
  -> full substituted source Jacobian
  -> quotient by source/reparametrization directions
  -> adjoint cokernel / Fitting class.
```

The mathematical target is the first nonzero block commutator (equivalently,
the Lyapunov--Schmidt obstruction after all later substitutions), not another
large terminal census.  The software target is a compiler pass that
automatically reimposes every earlier row after each restoration block,
derives the sparse left-null certificate, and refuses promotion without a
block-triangularity proof.

This transfers directly to TD6's moving-center/thickening atlas, maximum-12's
Q8 normalization/Taylor graph, GGV/Sigray reconstruction rows, and the
common-cubic lower Pfaffian system.  In each lane it asks whether a purported
terminal survivor is killed by a tiny omitted closure class before a large
elimination.  Falsifier: the full substituted Jacobian is actually block
triangular on the charged component and every curvature class reduces to
zero.  First experiments: exact sparse dependency/adjoint tables at the AS
base-519 point, the TD6 universal-cokernel section, and one selected-Q8
normalization point, with equivalent-presentation covariance controls.

## Bet 2: component factor of the Q6 left-null defect, then arithmetic Hensel

The three controls already show component dependence: two die at reimposed
G8; one reaches a three-row left-null certificate

```text
2 Q6[x^4 y^2] + 2 Q6[x^5 y] + R9[x^7 y^2] = 2.
```

Do not extrapolate this pointwise value.  Compute that adjoint pairing as a
function on the exact nonreduced predecessor/Q9/Q8/Q7 scheme, reduce it by
the source ideal, and form its Fitting/norm factor componentwise.  There are
only two high-value outcomes:

- it is a unit on every accepted component, giving a compact bounded-`D=7`
  exclusion; or
- its zero divisor contains a smooth component, furnishing the right seed
  for a common `Z_(3)` Hensel/Greenberg transition and a finite-state/lasso
  search.

The second outcome should then be compared, by invariants rather than visual
coincidence, with the balanced Artin--Schreier/Tate analytic factors and the
`(6,9)` Davenport--Stothers/common-cubic component.  The bridge test is
whether the same low-degree logarithmic-derivative or cyclotomic factor
controls the adjoint norm; a mere shared prime or degree pattern does not
count.  Falsifier: the pairing has no covariant definition under source
symplectic changes, or its zero divisor is entirely embedded/rank-zero and
has no field-valued branch.  First experiment: a source-hashed symbolic
pairing on the pinned base-519 fibre, followed by augmented-Fitting coverage
of all rank strata; search for a regular survivor before producing global
UNSAT certificates.
