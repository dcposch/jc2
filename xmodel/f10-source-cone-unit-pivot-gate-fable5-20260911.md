Unit test. Operations. Row swap, scaling a row by a proved unit, and row_i <- row_i - A_ik·row_k each have an explicit inverse over any commutative ring; column swaps are relabelings of unknowns recorded in a permutation. Invariant (own induction): at the start of step k, every row i>=k vanishes in columns <k. Base k=0 vacuous. A column swap among columns >=k leaves columns <k untouched; the row swap among rows >=k keeps the invariant; scaling keeps zeros; for i>k the update gives 0-A_ik·0=0 in columns <k and A_ik-A_ik·1=0 in column k. Rows <k are never touched again, so at termination the matrix is [U C; 0 R] with U k×k upper triangular with diagonal 1, C arbitrary, and R having no unit entry (or empty).

Solution. Setting the n-k nonpivot unknowns to zero makes every row i>k read 0=b_i whatever R is, including a nonzero all-nonunit R.
