## 1. Current public frontier

- [Gao, arXiv:2608.00222](https://arxiv.org/abs/2608.00222) concerns
  counterexamples in dimensions greater than two.  It does not reach the
  plane.
- The [SuperMind source ledger](https://github.com/SuperMindAI/Jacobian-Conjecture)
  still states that JC2 is open and that its four August 3 manuscripts give
  bounded or conditional structural results.  Its strongest advertised
  finite consequence remains the characteristic-zero lower bound 125.
- [Shaska, arXiv:2607.20210](https://arxiv.org/abs/2607.20210) proves that
  every nontrivially graded/equivariant plane Keller map is an automorphism,
  for every weight signature.  This is a genuine special-class wall, not a
  reduction of arbitrary plane Keller maps to the graded class.
- [Jelonek, arXiv:2607.20597](https://arxiv.org/abs/2607.20597) proves that
  the bounded-degree automorphism locus is Zariski closed inside the
  constant-Jacobian parameter space and gives a component dichotomy.  It
  supplies no irreducibility or component theorem that decides the plane
  case.
- The weighted Davenport--Zannier/tree papers found in the preceding sweep
  remain the newest directly actionable terminal-classification input.  No
  successor result invalidating or completing that pipeline was found.

## 2. Audit of a purported formal resolution

The repository
[AEjonanonymous/Jacobian-Conjecture-2D](https://github.com/AEjonanonymous/Jacobian-Conjecture-2D)
advertises a fully machine-verified resolution.  Its complete public Lean
source is only 90 lines.  The theorem named
`jacobian_conjecture_2d_established` has conclusion

```text
coeff 0 (jacobian P Q) != 0
```

under hypotheses

```text
jacobian P Q = C c
c != 0.
```

The proof rewrites the first hypothesis and returns the second.  It says
nothing about injectivity, surjectivity, existence of a polynomial inverse,
or automorphism structure.  Earlier “fiber” statements are likewise
existential tautologies (for example choosing the already supplied `Q_e` or
the zero polynomial).  A Lean kernel may therefore accept the file while it
does not state JC2.  This is not external progress and should not enter the
mathematical ledger except as a scope-warning example.
