## 3. New mechanism, and new connection

### 3.1 Mechanism `ACS` — asymptotic covering self-similarity, and the deficit–Euler identity

**Label: `NEW` to the campaign ledger; method family `KNOWN` externally
(Domrina/Orevkov/Żołądek). Mandatory primary-source check at the
2026-08-29T05:24Z sweep before any citation as campaign-original.**

Setup, all standard: `F=(f,g): A^2_C -> A^2_C`, `J(f,g) = 1`, `d = td(F)`,
`A = A(F)` the non-properness set. Write `delta(y) = d - #F^{-1}(y)`.

**(ACS-1).** `F` is étale everywhere (`J` is a nonzero constant), and by
Jelonek's definition of `A(F)` it is proper over `C^2 \ A`. Proper + quasi-finite
is finite; finite + étale is a covering; `C^2 \ F^{-1}(A)` is a plane-curve
complement, hence connected. Therefore

```text
F : C^2 \ F^{-1}(A)  -->  C^2 \ A
```

is a **connected finite étale covering of degree `td`**, and

```text
pi_1(C^2 \ F^{-1}(A))  <--->  index-td subgroup of  pi_1(C^2 \ A).
```

Both spaces are complements of curves in the affine plane. A counterexample is
therefore exactly a nontrivial *self-similar* pair of plane-curve complements.

Three immediate exact consequences the campaign does not currently have:

```text
(i)   e(C^2 \ F^{-1}A) = td * e(C^2 \ A)          [covering multiplicativity]
(ii)  kappa-bar(C^2 \ F^{-1}A) = kappa-bar(C^2 \ A)   [Iitaka, finite etale]
(iii) F^{-1}(A) -> A is etale, so every local analytic singularity type of
      F^{-1}(A) is a copy of one of A, with multiplicity d - delta(p).
```

(iii) is worth stating aloud: **the singularities of `F^{-1}(A)` are not new
data.** They are copies of `A`'s.

**(★) The deficit–Euler identity.** Stratify `A` by `A° = {A smooth, delta
locally constant}` (open dense, components `C`) and `S = A \ A°` (finite). Then
`F^{-1}(A) -> A` is a covering of degree `d - delta_C` over each `C` and has
`d - delta(p)` points over each `p in S`. Combining with `e(C^2) = 1`,
`e(C^2 \ Z) = 1 - e(Z)`, and (i):

```text
        sum_C  delta_C * e(C)   +   sum_{p in S} delta(p)   =   td - 1.        (★)
```

Derivation, three lines: `e(F^{-1}A) = sum_C (d-delta_C) e(C) + sum_p (d-delta(p))`;
`e(F^{-1}A) = 1 - d(1 - e(A))` and `e(A) = sum_C e(C) + #S`; subtract.

`(★)` is exact, unconditional for Keller maps, and — this is its point —
decomposes `td - 1` over the **target-side geometry of `A(F)`**. Contrast the
ledger's `td = sum e_S - b1 + 1`, correctly filed at 22:08Z as circular because
both sides are generic-fibre data. `(★)` is not circular in the same way; it is
merely *not yet bounded*, and it names precisely which quantities must be
bounded: the number of components, their `e(C)`, the generic deficits
`delta_C >= 1`, and the deficit jumps `delta(p) - delta_C >= 0` at the finitely
many special points. **The cofinal-ceiling problem is now a statement about the
singularities and component count of one plane curve.** I claim that as the
mechanism's whole value; I do not claim a ceiling.

Two sanity anchors, both checked: automorphism (`A = ∅`, `d = 1`) gives `0 = 0`;
the non-Keller control `F(x,y) = (x, xy)` fails the hypothesis exactly where it
must (`F` is not étale on `A`, so `F^{-1}(A) -> A` is constant, not étale) —
`(★)` does not apply and the identity does not falsely fire. That is the
negative control this mechanism admits, and it passes.

**(ACS-2) — the mechanism has teeth.** *If `A(F)` is empty or smooth and
irreducible, `F` is a polynomial automorphism.*

Proof, complete and desk-checkable. `A` smooth and one-place rational (Jelonek
J-1) makes `A ≅ A^1` embedded, so by Abhyankar–Moh–Suzuki `A` is a coordinate
line and `C^2 \ A ≅ C^* x C`, with `pi_1 = Z`. The unique connected degree-`d`
cover of `C^* x C` is `z -> z^d`, so `C^2 \ F^{-1}(A) ≅ C^* x C`. Let
`h` cut `F^{-1}(A)`. Units of `O(C^2 \ F^{-1}A) = C[x,y][1/h]` are
`c * prod h_i^{n_i}`; units of `C[u^{±1},v]` are `c u^n`; matching the unit
groups forces `F^{-1}(A)` irreducible with `h` corresponding to `c u`. Hence
every fibre `h^{-1}(lambda)`, `lambda != 0`, is `≅ A^1`, so `h - lambda` is a
variable by AMS, so `h` is a variable and `F^{-1}(A)` is a coordinate line.
Normalize `A = {v=0}`, `F^{-1}(A) = {y=0}`. Then `v∘F` vanishes exactly on
`{y=0}`, and the only units in `C[x,y]` are constants, so `v∘F = c y^m`.
Therefore

```text
J = (u∘F)_x * c m y^{m-1}  -  (u∘F)_y * 0  =  c m y^{m-1} (u∘F)_x  =  1,
```

forcing `m = 1` and `(u∘F)_x` constant, i.e. `F(x,y) = (alpha x + q(y), c y)` —
triangular, an automorphism. ∎

So **`A(F)` of a counterexample is reducible or singular.** I fully expect this
to be known in the Jelonek/Orevkov circle; I derived it rather than recalling
it, and it is flagged `KNOWN-PRESUMED` in §8. Its role here is not to be a new
theorem — it is to demonstrate that `(★)` + AMS is a *closing* method on this
object, which is exactly what the campaign concluded it was not.

**What `ACS` does not do.** No ceiling. No landing theorem. No statement about

any campaign genome, and constructing it remains the standing Avenue 7 debt.
