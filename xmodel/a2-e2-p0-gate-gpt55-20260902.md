## 4. RAY-1 N2 and RAY-2

On the Wall-B ray, I extracted the order-one-deeper rows by Laurent expansion at
infinity.  For `U>=3e+2`, at `e=1,2,3,4`, the rows match:

```text

N1:  alpha - beta + delta/2 = 0
N4:  n alpha - 2 beta - (n-2) gamma + (n-1) delta = 0
```

Old `N2` is exactly RAY's measured row:

```text

        + (4n+2e-5)gamma - (n-1)delta - epshat.
```

Correcting `EQ2` changes it to

```text

         + (4n+2e-5)gamma - (n-1)delta.
```

There is no `epshat` term.  Substituting `N1` and `N3` into `N2corr` gives `0`
identically.  Hence `epshat` is not constrained at this order and

```text

Surviving wall statement: deg E1 <= 2e-1 only.
Residual dimension: 3 parameters (beta, delta, epshat), not 2.
```

With the independent T2 sign correction, the boundary slice `U=3e` has a changed
inhomogeneity.  In normalized variables `a=b=eta_e=s_sigma=1`, the corrected
`N3` equation is


kills `U=3e` for `e>=2` because


Thus `RAY-DEP` survives, and `RAY-EDGE(e>=2)` survives after replacing `rho`.
The `(1,3)` edge cell remains a separate CAS cell; existing decisions used the
old row package and must not be consumed for the fully corrected system.
