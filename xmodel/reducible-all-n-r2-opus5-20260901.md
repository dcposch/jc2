## 4. THEOREM CAGE-N-R2

> **THEOREM CAGE-N-R2 `[D]` (promotion-safe scope).** Let `F` be a noninvertible
> plane Keller map of geometric degree `N >= 4` in scope RED-N. Then:
>
> 1. **Curves.** Every `D_i` is a polynomial curve (`D~_i ~ A^1`, one place at
>    infinity); all meet `L_inf` in one common point, one place each, of a common
>    Newton-Puiseux type `u = c v^{d/e}`; all degrees are positive multiples of
>    `max(d,e) >= 2`; no component is a line or a smoothly embedded `A^1`.
> 2. **Budget.** `sum_i W_i + K_tot = N - 1`, `c_l = mu_l s_l + K_l`;
>    `a_i >= m + K_tot >= 2`; `1 <= b <= floor((N-2)/2)`; `m <= N-2-K_tot`;
>    `s_l <= floor((N-2)/2)`.
> 3. **Local.** `a_p + sum_i r_{i,p} W_i + K_p = N`; the letters over `p` are
>    `a_p` fixed singletons plus one `G_p`-invariant cluster per point at infinity
>    over `p`, `G_p` transitive on each; distinct branches at `p` carry disjoint
>    meridians; no `G_p` is transitive on all `N` letters.
> 4. **Normalization gates.** If `D_i` owns a carrier with `s_l = 1`,
>    `corr_l = 0` - in particular any trivial dicritical - then `2 W_i <= N`
>    (SELF-R2) and no `s = 1` carrier on `D_i` has `K > 0` (ETA). If `b = 1` then
>    `2 W_br <= N` (LZ-KILL).
> 5. **Local analytic, conditionally.** At a correction point `t in l'` with
>    `mu_l = 2`, `ord_t phi_l >= 2`, off the contracted locus and off `L_inf`:
>    `e_t = 1` and the image germ is an ordinary cusp `(nu, nu+1)` with
>    `M_t = nu+1`, `k_t = nu-1` (CUSP-2R). If every `h_l`-ramification point of a
>    `mu_l = 2` carrier lies off the contracted locus, then `s_l = 1` (NO-RAM-2R).
>    Unconditionally every ramified carrier is dead for `N <= 7` by clause 4.
> 6. **Monodromy.** `rho : pi_1(C^2 - D_br) ->> G <= S_N` is transitive with
>    nonabelian image; `gamma_i` has cycle type `1^{a_i} prod_{l -> i} mu_l^{s_l}`,
>    i.e. moved type `lambda_i` with `N - |lambda_i|` fixed letters. If **every**
>    branched meridian is a transposition then `G = S_N`; otherwise `G` may be
>    imprimitive, and no pin is available.
> 7. **Degree.** `sum_i d_i iota_i = N - 2 + 2g + Sigma_inf >= N - 1`, conditional
>    on the generic-line surjection. If the `d_i` meridians of `D_i` on a generic
>    line generate transitively - in particular if `b = 1` - then
>    `d_min(D_i) . iota_i >= N - 1`.
> 8. **Gauge.** `K_N != {}` implies `sup_{F in K_N} deg A_F = infinity`; a
>    universal raw-degree cap would imply `K_N = {}`. Geometric genus and the
>    affine singular points with their analytic types are automorphism invariants,
>    hence *not* unbounded.

Clauses 1-4 and 6-8 are unconditional at their stated scopes; clause 5 is
conditional as marked; clause 7 carries `OPEN[ZARISKI-GENERIC-LINE-CUSTODY]`. No
clause is an attainment claim.
