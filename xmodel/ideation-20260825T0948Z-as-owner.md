## 3. New mechanism and cross-connection

### Rational stable-image obstruction

Instead of first proving that ambient characteristic-zero components cannot
merge under reduction, compactify the **actual source trajectory**.  After a
finite DVR extension and semistable reduction, a rational generic source has
a special fibre that is a tree of `P1`s.  The normalization of every
nonconstant image component is therefore rational.  If exact completed-local
source rows show that one nonconstant special source component follows the
formal `H` branch at a selected contact, it would dominate the normalization
of `H`, contradicting `g(H)>0`.

This is a new route around part of the no-merger burden, not a theorem yet.
It connects rows 7 and 31 (proper graph/valuative extension) with rows 25--28
(the selected branch, genus, and infinity passport).  It still owes proper
extension of the source graph and exact identification of the special formal
branch; merely passing through the same point is insufficient.

restoration matrix over the accepted predecessor scheme.  Q8 formal-branch
uniqueness is likewise a rank/Fitting question for the full-source local

serve all three if it retains the original nonreduced ideal, pivot-zero

nonmembership is never substituted for pointwise solvability.
