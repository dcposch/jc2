For a fixed total map degree `D`, represent a depth-`n` map by its base-three

```text
R_n = (det J(F_n)-1)/3^n mod 3.
```

Because the special fiber has differential matrix congruent to the identity,
the next digit `(U,V)` changes `R_n` by `U_x+V_y`.  First apply the Cartier
projection

```text
C(R_n) = sum r_(3a+2,3b+2) X^a Y^b.
```

A nonzero coefficient is a terminal obstruction.  If it vanishes, solve the
truncated divergence equation, retain **all** divergence-free Hamiltonian,
Frobenius-horizontal/vertical, and cap-boundary modes as genuine successor
choices, compute the next integer carry, and recurse.  Merge nodes only when
their complete truncated map coefficients and carry state are canonically
equal, or when a separately proved exact symmetry identifies them.  This is
a finite DAG for each `(D,n)`; it is not an asserted stationary finite-state
automaton across all depths.

Emit the same finite system in two independent forms:

1. sparse integer polynomial equations for SAT replay; and
2. a canonical one-hot trit encoding with multiplication/addition truth

**Dependencies.**  The packet's exact F-only equation and constant-target
normalization; the reviewed Cartier/divergence identity; fixed total-degree
