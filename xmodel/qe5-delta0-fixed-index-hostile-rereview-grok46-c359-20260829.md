## 6. Proposition 4.1, re-derived

**Statement (independent).** Under the §4.1 contract, every R2.2-admissible
equal-regime pattern satisfies

```text
D = nu_G * A,     A = mu*s - Sm,
A >= s >= 1,
dq <= 1 + nu_G + D <= 1 + 2D,
gcd(M_G, nu_G) = 1,
M_G * nu_G | D,
dq/D <= 2 + 1/(M_G * nu_G),
K = mu*w*dq/D <= mu*w*(2 + 1/(M_G * nu_G)).
```

Hence the candidate menu

```text
Kset = { K in Z : w < K <= mu*w*(2 + 1/(M_G*nu_G)), gcd(K, nu_G)=1 }
```

is finite. For `w in Q_{>0}` it is exactly enumerable by ranging
integers from `floor(w)+1` to `floor(bound)`; no numerical cutoff.

**Proof.** Equal-regime degrees:
`dp = mu + nu*(mu + Sm)`, `dq = 1 + nu*(1+s)` with `nu = nu_G`. Then

```text
D = mu(1 + nu(1+s)) - (mu + nu(mu + Sm))
  = nu(mu*s - Sm) = nu*A.
```

R2.2 (`:348-350`) gives every arriving multiplicity strictly larger
than every nonchain multiplicity, so `m_j <= mu-1`, hence
`Sm <= k(mu-1)` and

```text
A = mu(k+lex) - Sm >= k + mu*lex >= k + lex = s.
```

S (`:347`) is `mu*dq > dp`, i.e. `D > 0`. If `s=0` then `k=lex=0`,
`dp = mu(1+nu) = dq * mu`, so `D=0`, contradicting S. Thus `s >= 1`
and `A >= 1`, hence `D = nu*A >= nu`. Then

```text
dq = 1 + nu(1+s) <= 1 + nu + D <= 1 + 2D,
```

the first because `D >= nu*s`, the second because `D >= nu`.

R1.0/R2.2: `dq ≡ 1 (mod nu)`, so `gcd(dq, nu)=1`. `M_G = gcd(dp,dq)`
therefore satisfies `gcd(M_G, nu)=1`. Also `M_G` divides `dp` and
`dq`, hence divides `D`. Combined with `nu | D` and coprimality,
`M_G * nu | D`, so `D >= M_G * nu` and `1/D <= 1/(M_G * nu)`. With
`dq <= 1+2D`,

```text
dq/D <= 2 + 1/D <= 2 + 1/(M_G * nu).
```

Nonzero-edge handshake `X/K = dp/dq` with `X = mu*(K-w)` rearranges to
`K = mu*w*dq/D`. N1 supplies integer `K` and `gcd(K, nu)=1`. QED.

**Cap vs sharpness vs attainment.** This is a *safe exact cap* on every
admissible `K`: no admissible value is excluded, and the bound is an
explicit rational, not a numerical cutoff. It sharpens the Opus 5
successor cap `2 + 1/M_G` (`Opus` `:464-473`), because `nu_G >= 2`
makes `1/(M_G*nu_G) < 1/M_G`. It is *sharp at the pattern-law tier*
when `s = A = 1`: then `D = nu`, `M_G * nu | D` forces `M_G = 1`, and
`dq = 1+2nu = 1+2D`, so `dq/D = 2 + 1/nu = 2 + 1/(M_G*nu)`. Integer/N1
attainment of the numerical value `mu*w*(2+1/(M_G*nu_G))` depends on
`w`. Control 6.1 is a witness of integer attainment (`K=5`). For
`M_G > 1` the displayed ratio bound is safe and not attained (then
`s >= 2` or `D > nu`). This is a floor/cap claim with an identified
equality case, not an attainment theorem for every record
(FALLACY.md floor/attainment).

Rational `w` makes `Kset` a finite set of integers. Enumerability is
exact.

## 7. Proposition 5.1 as an iff for the R2.2 factor grammar

**Statement (independent).** Fix a §4.1 record and `K in Kset`. Put
`X = mu*(K-w)`, `(a,b)` the reduced positive fraction `X/K`,
`dp = M_G*a`, `dq = M_G*b`. There exists an R2.2 factor-pattern witness
at the forced target index `nu = nu_G` if and only if all of the
following hold.

1. `dq ≡ 1 (mod nu)` and `dp ≡ mu0 (mod nu)`. Under the contract
   `mu0 = mu`, the second is `dp ≡ mu (mod nu)`.
2. `s = (dq-1)/nu - 1` and `Sm = (dp-mu0)/nu - mu` are integers with
   `s >= 1`, `Sm >= 0`.
3. `D = mu*dq - dp = nu*(mu*s - Sm) > 0`. (The producer’s extra
   `K*D = mu*w*dq` is an identity of the construction.)
4. If `Sm = 0`: take `k = 0`, `lex = s`. No nonchain orbit. The law
   “`k>0` forces `dq < dp`” is vacuous. S is `D>0`.
5. If `Sm > 0`: require `dq < dp`, set `mmax = floor((dp-1)/dq) >= 1`
   and `kmin = ceil(Sm/mmax)`, and require `kmin <= s`. Then a
   positive `k`-part partition of `Sm` with every part in `[1, mmax]`
   exists for every `k` in `[kmin, min(s, Sm)]`; the canonical witness
   uses `k = kmin`, `lex = s-k`.

This is an equivalence for the promoted R2.2 *factor-pattern grammar*
(`BOOK-OFFAXIS.md` `:341-355` plus R1.0 `:227-231`). It is not an
existence theorem for Proposition 8.1(iv), a Puiseux edge, a polynomial
Keller pair, a priced route, or i-sync.

**Forward.** An R2.2 witness at `nu_G` has the two congruences, the
displayed formulae for `s, Sm`, S (`D>0`), R, and `M_G = gcd(dp,dq)`.
Handshake pins `(dp,dq)` once `M_G` is given. If `Sm>0` then `k >= 1`,
so R2.2 forces `dq < dp` and strict NE `1 <= m_j <= floor((dp-1)/dq)`.
Also `k <= s` because `lex = s-k >= 0`. A bounded positive partition of
`Sm` into at most `s` parts of size `<= mmax` exists iff
`ceil(Sm/mmax) <= s`. Q-only orbits are exactly the `lex` extras; the
0-direction contributes `eta^{mu0}` in `p` and the simple factor `eta`
in `q`, not an extra `nu`-orbit (`r0` counts nonzero arrivals only).

**Reverse.** The constructed multiplicities, one nonzero arrival orbit
of multiplicity `mu`, zero-factor `eta^{mu0}` with `mu0=mu`, and `lex`
simple q-only orbits realize the R2.2 factor degrees. S holds for both
arrivals by `D>0`. R holds for arrival/zero multiplicity `mu` by
`D>0`, and for each nonchain multiplicity by strict NE. From `D>0` one
has `dp <= mu*dq - 1`, hence `mmax = floor((dp-1)/dq) <= mu-1`, so the
orbit-comparison law is free once S holds. `M_G = gcd(dp,dq)` holds by
construction.

**Partition existence, no search.** `mmax >= 1` and `Sm >= 1` give
`kmin <= Sm`. By definition of ceil, `Sm <= kmin * mmax`. Starting from
`kmin` ones and distributing `Sm - kmin` extra units never exceeds
`mmax`. So the inequality is necessary and sufficient; no partition
enumeration is required for existence.

**Edge cases.**

- `s = 0`: excluded by S (`D=0`).
- `Sm < 0`: rejected by item 2.
- `mmax = 0`: equivalent to `dp <= dq`. Incompatible with `Sm>0`
  (which needs `k>=1`, hence `dq<dp`). Item 5 rejects it.
- Repeated roots: the grammar assumes distinct formal `d_j`. Root
  coincidence is coefficient/ODE realization, outside the iff.
- Unaccounted q-orbit: R1.0/R2.2 q-shape is `eta`, each nonzero
  p-orbit once, and `lex` simple extras. No further orbit is licensed
  or omitted.
- N1 lives in `Kset`, not in the factor-grammar iff. That typing is
  correct: N1 is vertex admissibility (`SHEET6-III.md` `:123-129`), not
  a polynomial-shape law.

**Bug-finder (not a proof).** Exact-rational exhaustive check over
`mu in {2,3,4}`, `M_G in {1,2,3}`, `nu_G in {2,3,4,5}`, seven rational
`w` values, and every `K in Kset` (1442 members): Proposition 5.1
agreed with a brute `k`-existence search in every case (114 exists,
1328 dead, 0 mismatches). Non-unique `(k,lex)` occurred, as required.

Repair R3 below is only the displayed congruence `dp ≡ mu0`, not a
change of the equal-regime theorem.
