## Hidden assumptions and invalid implication

1. **TD6 has no full base solution on the fixed A3 slice.**  Its reviewed unit
   appears at current, while the 24-dimensional object is a kernel of the
   earlier transport/FIRST/previous-pole prolongation.  Therefore its `K2` is
   a staged partial-solution obstruction, not a Kuranishi map of a point of
   the full TD6 solution scheme.  Cotangent-complex language is licensed only
   relative to that truncated stage.
2. **Zero K2 plus a zero presentation/Spencer check is weak.**  It can mean
   merely that the earlier symbol is involutive or that q-boundary motions are
   absorbed by the 132 transport variables.  It neither integrates the
   partial solution nor changes the already present current-stage unit.  A
   genuine Spencer statement would require the full symbol complex and its
   prolongation maps; the launched reverse-row control checks presentation
   independence only.
3. **A typed ring is not a typed deformation functor.**  Exact arithmetic
   prevents the V84 scalar-coercion bug, but does not establish quotienting by
   the full source reparametrization/gauge action, normalized-section
   transversality, source-chart landing, flatness across denominator factors,
   or finite determinacy.  Those must be separate proof-carrying interfaces.
4. **One principal-open kernel cannot be glued by basis names.**  Quadratic
   tables from different rank charts live in quotient modules related by
   transition maps, not by serialized coordinates.  A global obstruction
   needs a module/Fitting or Cech certificate; zero tables chartwise are not a
   cover until the opens and transitions are exact.
5. **Order-two transfer is architectural only.**  There the Kuranishi map is
   based at an actual first-normal component and its half-weight kernel has a
   geometric normal-cone meaning.  TD6's staged empty-slice calculation and
   D1's filtered source lift do not inherit that meaning from a shared API.

Thus the implication

```text
K2 = 0 and reverse/Spencer check = 0  => useful TD6 escape or smooth family
```

is invalid.  At most it says that a specified partial-stage quadratic class
vanishes on a specified principal open and is stable under one exact change
of row presentation.

## Cheapest separating experiment

Before completing all 300 previous/pole pairs, compute the full **current
affine obstruction class restricted to the 24-dimensional Stage-A kernel**,
including its constant unit and every source-combination/denominator.  This
single map distinguishes the cases that matter:

- if the constant unit remains a unit modulo the coefficient ideal, the
  earlier zero K2/Spencer result is irrelevant and the neighborhood is empty
  on that chart;
- if the coefficient ideal has a proper zero locus, it names the exact
  weighted successor/factor strata;
- if the class vanishes identically after a source lift, only then is a
  higher K2/K3 atlas justified.

As a cheap implementation falsifier, one mixed q/dead block (for example
block `(0,5)`, not another q-only block) should be compared under forward and
reverse source-row presentations.  A nonzero class immediately refutes the
blanket-zero hypothesis; a zero only validates that block.
