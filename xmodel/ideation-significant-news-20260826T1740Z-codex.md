## Exact deductions

### Finite-state recursion: exact finiteness, missing termination

Define a predecessor state by factor type of the first normal block, projectivized kernel support, visible graph deviations, and relative gaps to the next center/load/target/intrinsic terms. For a fixed pole ceiling and finite source-family list, transitions are determined by finitely many affine-linear valuation comparisons. Hence, on a rational polyhedral cone with uniformly bounded source list and pole ceiling, there are finitely many **combinatorial transition types**. This follows from finite support. It is not termination.

Termination needs a well-founded quantity decreasing at every nonterminal transition. A candidate is the lexicographic tuple

```
(unsolved projective kernel dimension,
 unconsumed deviation coordinates,
 normalized gap to the intrinsic cubic,
 factor-partition defect).
```

H16 proves that raw grade and equation count are not monotone: a new deviation can absorb an obstruction. A theorem must show that absorption consumes a deviation permanently or forces strict specialization. Compute two successors after the H16 mixed face and search for a directed cycle modulo scaling. A cycle kills the naive theorem; acyclicity plus a machine-found ranking function gives a credible lemma.

### TD6 FIRST is a split complex; P12 is a transferred obstruction

Write the 38 FIRST equations as `d:E -> W` over the localized q-ring. A polynomial inverse on a 38-column block makes `d` split on that summand. Eliminating FIRST is passage to the cokernel of a split presentation. Literal P12 therefore defines a transferred residual class.

This yields a checkable invariance statement: for two unimodular FIRST splittings over the same ring, reduced P12 remainders have the same class modulo the residual source module. Compare the cyclic q14 inverse and acyclic high-q inverse. If their 17-term expressions differ but their classes agree, the terms are presentation artifacts. If a nonzero Fitting/Ext class persists until `F` is adjoined, total-`F` is a genuine null-homotopy.

The natural model is the two-term complex `[E -> W]`, with P12 as curvature, and the mapping cone of multiplication by `F`. V89K1 suggests that `K` becomes the unit `B3` in this cone. That interpretation is conjectural until explicit chain maps are emitted, but it is cheaply falsifiable by computing the P12 class and Fitting annihilator before and after the cone.

### Uniform D1 moving-root functional

The promoted odd recurrence is already a left-kernel vector annihilating every allowed source column and pairing nontrivially with the target. For remaining `d=2,3` cells, build a symbolic support matrix over chamber variables and solve

```
L(source family)=0 for every timing in the chamber,
L(target)=a unit or a named boundary factor.
```

The functional should be piecewise polynomial/rational in `a,d,s`, with wall corrections at `a=7,8,9`. A globally constant vector is unlikely. Failure is informative: zero target pairing identifies precisely the equality face requiring a predecessor.

### Local-to-global formulation

The total-Rees object should map every DVR arc to a finite support state. The needed result is not coverage of one coordinate model but properness/valuative completeness of this state map, with every closed specialization landing in a registered successor. A practical certificate is a finite fan with two-sided specialization maps and compatible obstruction functionals on every codimension-one wall.

D1 and affine-Faber functionals, and TD6's transferred P12 class, may then be sections of a constructible obstruction module on this fan. Unit support on every cone plus compatible wall restrictions would empty the fixed atlas. This still does not provide a cofinal sheet bound, but it would turn one fixed book from a chart collection into a theorem.

## Conjectural mechanisms and falsification tests

1. **Finite automaton conjecture.** Modulo ramification scaling and graph changes, every affine-Faber transition reaches a unit, lowers kernel dimension, or consumes a deviation. H16 is the first honest stress test.
2. **P12 curvature conjecture.** The repeated 17-term remainders are one universal class transported through q-degree; total-`F` null-homotopes it. Test cokernel equality, not term-list equality.
3. **D1 generating functional.** Finite-band dual vectors specialize a rational function in the shift operator; exceptional load timings appear as finitely many residues.
4. **Cech obstruction.** The landing gap is a nonzero Cech class measuring failure of local obstruction sections to glue. This explains how many local cells can die without a global theorem.
5. **Reduced counterexample search.** Search only unresolved wall schemes: D1 `d=2,3` load-sensitive faces, H16 rational equality faces, and simultaneous TD6 low-q modulo FIRST and `F`.
