## Promoted theorem

Let `I22` be the ideal over Q generated by the 21 frozen exact-Q V9 rows
`Tg10_1..Tg12_7` and the frozen V17 row `Tg14_5`.  There is an exact
characteristic-zero closed point of

```text
V(I22) intersect V(k) intersect D(cs*k1*rho).
```

One field of definition is

```text
K = Q(i,sqrt(2))[alpha]/(alpha^2-sigma),
sigma=(5/48)(1-i)(1+sqrt(2)).
```

Send `cs=rho=k1=1`, `k=rs=c0=c1=0`, set every unlisted name to zero, and
set

```text
a0 = alpha
a1 = i*(sqrt(2)-1)*alpha
e0 = (sqrt(2)-2)*(1-i)*alpha
e1 = -sqrt(2)*(1+i)*alpha
k2c = (1/8)*(1-i)*(1-sqrt(2))
rs1 = (1/6)*(1+i)*(1-sqrt(2))
k10_4 = (1+i)*(275/256-(827/768)*sqrt(2))
         +(i/3)*(1-2*sqrt(2))*alpha.
```

Exact sparse substitution sends all 22 rows to zero.  The point extends to
the honest ordered `T-cs` presentation with `qrs=qc0=qc1=0`; at the point
`cs*k1*rho=1` and `k=0`.

Consequently, for all nonnegative `a,b,c`,

```text
cs^a*k1^b*rho^c is not in radical(I22+(k)).
```

In particular, after localizing by `cs*k1`, no power of `rho` belongs to the
frozen-prefix ideal.  A solver using only these 22 rows cannot certify
emptiness or rho nilpotence on the delayed-load open.
