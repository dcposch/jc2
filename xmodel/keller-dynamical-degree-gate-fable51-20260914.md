## Independent derivation

Compactification and degrees. Let D = max deg F_i and homogenise: f = [z^D F_1(x/z,y/z) : z^D F_2(x/z,y/z) : z^D]. A common factor would divide z^D, but z does not divide the component attaining degree D, so f is the reduced rational extension, deg f = D, the indeterminacy set I(f) lies in {z=0}, and f maps H_infinity minus I into H_infinity. DNT's iterate f^n is the meromorphic extension of the composition on a Zariski-open set; since F is holomorphic on C^2 with F(C^2) inside C^2, f^n = F^n on all of C^2 and deg f^n = deg F^n. On P^2, H^{1,1} is spanned by the Kähler class and (f^n)^* multiplies it by deg f^n, so the DNT definition (line 227) gives d_1(f) = lim (deg F^n)^{1/n} = lambda_1(F); the limit exists by submultiplicativity. The generic fibre of f over a point of C^2 is the fibre of F, so d_t(f) = [C(x,y):C(F_1,F_2)] = d (characteristic zero; F is dominant because c != 0 makes it a local biholomorphism with open image). The degrees 1, lambda_1, d are correctly identified.

Hypothesis. DNT require d_t > d_p for all p < k, which by their log-concavity remark (line 239) is just d_t > d_{k-1}, here d > lambda_1. If d = 1 the claim reads lambda_1 >= 1, true because every F^n is non-constant (det D(F^n) = c^n != 0). If d >= 2, assume lambda_1 < d for contradiction; the hypothesis then holds. Theorem 1.1 asks for nothing else: no affine properness, holomorphic extension, algebraic stability or polynomial-like trapping appears in its statement, and DNT define the dynamical degrees by the limit as bimeromorphic invariants.

Affine repelling point. With Q_n = RP_n, Theorem 1.1 gives d^{-n} sum_{a in RP_n} delta_a -> mu weakly on the compact space P^2. H_infinity is a proper analytic subset, so mu(H_infinity) = 0 (lines 43-52). The producer asserts a suitable test function without justification; here is the argument. mu is a Borel probability measure on a compact metrisable space, hence inner regular, so some compact K inside C^2 has mu(K) > 1/2. Urysohn's lemma on P^2 gives continuous phi, 0 <= phi <= 1, phi = 1 on K, phi = 0 on H_infinity. The integral of phi against mu is at least 1/2, so for large n the sum of phi over RP_n is positive and some a in RP_n lies in supp phi, inside C^2. That point belongs to the honest graph: on C^2, f^n = F^n is holomorphic, so (a,a) in the graph closure means F^n(a) = a, and the differential of f^n at a is D(F^n)(a). DNT's regularity condition f^i(a) not in I (line 920) is automatic because the orbit stays in C^2 and I lies in H_infinity. DNT's repelling condition (line 917) is that every eigenvalue of D(F^n)(a) has modulus strictly greater than 1. Graph-intersection points at infinity never enter.

Chain rule. D(F^n)(a) = DF(F^{n-1}a) ... DF(a), all factors evaluated in C^2, so det D(F^n)(a) = c^n. The two eigenvalues satisfy lambda lambda' = c^n with |c^n| <= 1, so they cannot both have modulus > 1. Contradiction, hence lambda_1 >= d. |c| = 1 gives |c^n| = 1 and |c| < 1 gives |c^n| < 1; both are covered. For |c| > 1, |c^n| > 1 permits two eigenvalues of modulus > 1, so this argument yields nothing; the producer correctly leaves it out and makes no claim that a scaling normalisation preserves lambda_1.

## Hostile checks

1. Compactification eligibility and degree identification: PASS, as derived above.
2. Equidistribution forces an affine regular repelling orbit: PASS, with the test-function existence supplied here.
3. Determinant chain rule, eigenvalues, |c| = 1, |c| < 1, d = 1, exclusion of |c| > 1: PASS.
4. Automorphism consequence: PASS. Polynomial automorphisms alpha, beta of C^2 have constant Jacobians, det D(alpha F beta) = det alpha times c times det beta, and alpha, beta are bijections so alpha F beta has generic degree d. With determinants 1 and c = 1 the theorem applies afresh. No invariance of lambda_1 is used, and none holds in general: swap composed with H_2 is (y^2 - x, y), an involution with lambda_1 = 1, whereas lambda_1(H_2) = 2. The general multiplier condition is |det alpha| |det beta| |c| <= 1; the producer claims only the determinant-1 case and does not extend silently. Excluded regime: DNT line 239 records d_1^2 >= d_0 d_2, so lambda_1 >= sqrt(d) for every dominant rational self-map of P^2; the claim removes the window [sqrt(d), d), and "lambda_1^2 = d impossible for d > 1" is its special case.
5. Controls: PASS. Identity: c = 1, d = 1, deg F^n = 1, so lambda_1 = 1 = d. H_m = (y, y^m - x): DH_m = [[0, 1], [-1, m y^{m-1}]] has determinant 1; the inverse (x,y) -> (x^m - y, x) shows d = 1; by induction the second component of H_m^n has leading monomial y^{m^n}, since (y^{m^{n-1}})^m dominates the subtracted first component of degree m^{n-1}, so lambda_1 = m > d: no upper bound, no equality. (x^2, y^2): det DF = 4xy is not constant, d = 4, deg F^n = 2^n so lambda_1 = 2 < 4, and (1,1) is fixed with DF = diag(2,2), repelling with determinant 4^n at period n; the constant-Jacobian hypothesis is load-bearing and the example is consistent with DNT. Counterexample search: every known Keller map of C^2 is an automorphism with d = 1, where the claim is trivial; a counterexample to the claim would itself be a Jacobian Conjecture counterexample with lambda_1 < d. None exists in the record. Nothing REFUTED.
6. Closing test: PASS as stated, no change. The result is a necessary condition on a hypothetical counterexample, namely degree growth at least d^n. Equality and faster growth remain open; no existence, minimisation, properness, inverse or candidate is supplied. It is a source implication, not a proof or novelty claim. The trivial corollary lambda_1 <= deg F gives d <= max(deg F_1, deg F_2) for a normalised counterexample; its literature status was not checked and it is not promoted.
