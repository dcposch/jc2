## 3. New mechanism and new connections

### 3.1 NEW mechanism: `ARITH-SPREAD` — multi-prime constructible-image census

**The repair that motivates it.** Grok's D43 scan chain C1 asserts: if the
sealed rows `F` (coefficients in the `S`-inverted order `A_S`, `S={2,3,5,7}`)
reduce to zeros at both registered frames, then `1 ∉ (F)⊗K_i`, "because the
same Bézout identity would reduce to `1=0` in `F_p`."  **That inference has a
denominator hole.**  A Bézout certificate over the *field* K0 has cofactors
with uncontrolled denominators; clearing them yields only a nonzero content
`D ∈ A_S` with `D ∈ (F)·A_S[W,...]`, and reduction at a frame gives `D ≡ 0
(mod P_p)` — which is satisfiable when `P_p | D`.  Exact toy refutation of
the literal inference: `F = {105337·105673}` has coefficients in `A_S`,
reduces to `0` at both registered frames (every frame point is a zero of the
reduction), yet `1 ∈ (F)⊗K0`.  So the two-frame version of C1 proves only:

> **(C1-repaired)** Any unit-ideal (emptiness) certificate for the charged
> system over K0 has content `D` with `N_{K0/Q}(D)` divisible by every prime
> whose frame is a zero of the reduction — currently `105337·105673`.

This is a certificate-shape constraint, not nonemptiness.  (Over a
non-field K0 the argument must run componentwise; the provisional field
theorem removes that caveat — a second load-bearing K0 use.)

**The escalation, which is the new mechanism.**  Let
`X = Spec(A_S[W,...]/(F)) → Spec(A_S)`.  By Chevalley the image is
constructible in the one-dimensional `Spec(A_S)`, hence either contains the
generic point (⟺ `1 ∉ (F)⊗K0` ⟺ `V(F)` geometrically nonempty over
char 0) or is a **finite** set of closed points.  Therefore:

- **Per-prime question (exact, cheap):** for a maximal ideal `P|p` of
  `A_S`, "is the reduced ideal proper over the residue field?" — one
  modular Gröbner basis, an exact per-prime theorem, orders of magnitude
  cheaper than the char-0 monoliths that capped.  (The banked pointbanks
  already answer YES at 105337 and 105673.)
- **Aggregation, nonempty direction:** proper fibers over infinitely many
  rational primes ⟹ the generic fiber is nonempty over `Qbar` — a
  theorem, not navigation.  At finite count `k`, the exact content bound
  `N(D)` divisible by all `k` primes (`≳ 10^{5k}`) makes emptiness
  certificates quantitatively predictable and checkable.
- **Aggregation, empty direction (symmetric):** if the generic fiber were
  nonempty, all but finitely many primes have proper fibers; so unit
  fibers at infinitely many primes ⟹ the generic fiber is **empty**.  A
  single unit prime is already the first genuine emptiness signal ever
  seen for this cell and immediately redirects the exact elimination.

This respects every standing firewall: no single-prime char-0 inference,
no CRT coordinate reconstruction (the mechanism yields existence *without
coordinates*, or certificate-shape constraints — never a point), and it is
disjoint from avenue 37.  Frame supply: a prime carries frames iff it
splits completely in K0 — density 1/9 among `p ≡ 1 (mod 168)` by Chebotarev
(instant cubic-character pretest); non-split primes can be censused over
their honest residue fields `F_q` if ever needed.  One proper frame per
prime suffices for the image argument; Galois stability of the selected row
set (Opus item H) is **not** assumed.

History labels: two-frame shield **KNOWN** (Grok C1) — with the above
**NEW** correction, which must gate any synthesis use of C1's
