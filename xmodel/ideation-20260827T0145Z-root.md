The reviewed rho-unit lemma is deliberately an empty-special-fibre tool.  A
different sufficient condition handles residual components that are
nonempty at `rho=0`: if, after honest chart saturation and genuine

```text

```

for some `N`, then there is no map to a domain/DVR in which `rho` is nonzero.

though its special fibre is nonempty.  This is elementary but absent from
the current staged certificate interface.  It connects Rees/normal-cone

### 3.3 New counterexample connection: p-adic Newton polygons meet JvdK descent

Write

```text
P=sum_i p_i(x)y^i,   Q=sum_j q_j(x)y^j
```

over `Z_109`.  On every top `y` face, the Jacobian coefficient gives

```text
n p_m'(x) q_n(x) - m p_m(x) q_n'(x) = 0.
```

AS-TRI used the `n=1` case plus Gauss valuation to obtain an integral,
residue-preserving target shear.  The proposed extension records every
coefficient as `(i,v_109(p_i))` or `(j,v_109(q_j))`, applies the same UFD
relation face by face, and asks whether the common-power factor licenses an
integral target shear or forces a new lattice slope.  The residue seed pins
`P mod 109=x-x^109` and `Q mod 109=y`, so any shear must also be tested for
residue preservation; valuation zero is not enough.

This is a genuine connection among AS/Witt lifting (19), p-adic injectivity
(21), JvdK descent (5), face isolation (12), and relative Newton geometry
(38).  It may yield either a finite-support impossibility theorem or the
first principled support shape for a counterexample search.

## 5. Software acceleration

Build a reusable **telescoping certificate IR**.  Given a polynomial circuit
`H(z)`, an affine/triangular normal-form map `z -> phi(z)`, and explicit
relations

```text
z_i-phi_i(z) = sum_j A_ij(z) F_j,
```

```text
H(z)-H(phi(z)) = sum_i D_i H(z,phi(z)) (z_i-phi_i(z))
```
