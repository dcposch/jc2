## 1. The total Kummer torsor — CONFIRM, with a base/component qualifier

Work geometrically over `C` (equivalently base-change a characteristic-zero
campaign field so that `mu_4` and the roots are available).  Put

```text
U = Spec C[X,H^-1],
V_H = Spec O(U)[p]/(p^4-H).
```

Since `p` is a unit on `V_H`, `4p^3` is a unit.  Thus `V_H -> U` is finite
etale of degree four, with the usual `mu_4` action.  As an `O(U)`-module,

```text
O(V_H) = direct_sum_(j=0)^3 O(U) p^j,
d(fp^j) = (df + (j/4) f dH/H) p^j.
```

After the `mu_4` base change these are the four character summands, so

```text
H^1_dR(V_H) = direct_sum_(j=0)^3 H^1_dR(U,nabla_j),
nabla_j = d + (j/4)dH/H.
```

This part of Opus's mechanism is exact.

There is one necessary scope repair.  When `H` is a proper power, the full
torsor can be disconnected, while R7R1's notation `L=C(X)(p)` selects a
field component.  On branch P, `H=A^2`, the full degree-four torsor has two
quadratic components; the selected R7R1 field is only one of them and does
not carry the full `p -> i p` automorphism.  The full torsor remains valid
geometric bookkeeping, and exactness transports between the two isomorphic
components, but it must not be identified literally with the selected
field.  In particular, branch P's four-row sum counts two gauge-equivalent
copies of each of the two component character spaces.

## 2. Topological capacity identity and all-`m` index — CONFIRM

Let `r=deg rad(H)` and let the geometric root multiplicities be `e_i`.
The base has `chi(U)=1-r`, hence etale multiplicativity gives

```text
chi(V_H)=4(1-r).
```

The monodromy image is generated by `zeta^(e_i)`.  Therefore the geometric
component count is

```text
c = gcd(4,e_1,...,e_r)
  = #{j in Z/4 : 4 divides j e_i for every i}.
```

Since a smooth affine curve has no `H^2`,

```text
b_1(V_H) = c-chi(V_H) = 4(r-1)+c.
```

Independently, `nabla_j` is regular singular.  Its horizontal section is
`H^(-j/4)`, which belongs to `O(U)` exactly when `4 | j e_i` for every
`i`.  Writing this indicator as `k_j`, the index formula gives

```text
h^1(U,nabla_j)=r-1+k_j,
sum_(j=0)^3 h^1(U,nabla_j)=4(r-1)+sum_j k_j=b_1(V_H).
```

Multiplication by `H` is the gauge intertwiner

```text
nabla_m(Hc)=H nabla_(m+4)(c),
```

so the dimension law is valid for every integer `m`, not only a stable
polynomial window.  This confirms Opus's all-`m` proof and its exact frozen
checks:

| fixture | `r` | `c` | `b_1(V_H)` | 12-row target sum |
|---|---:|---:|---:|---:|
| P, multiplicities `(2,2,2,2)` | 4 | 2 | 14 | 42 |
| Q, multiplicities `(2,2,2,1,1)` | 5 | 1 | 17 | 51 |
| `(8)` control | 1 | 4 | 4 | 12 |
| squarefree degree-eight control | 8 | 1 | 29 | 87 |

Thus `42/51/12/87 = 3 b_1(V_H)` is **CONFIRMED**.

## 3. Four characters versus infinitely many rows — REPAIR

For row `m=n+22`, R7R1 supplies a class

```text
[q_n dX] in H^1_dR(U,nabla_m),
```

and `nabla_(m+4)` is gauge-isomorphic to `nabla_m`.  Consequently any four
consecutive rows have target-space dimensions summing to `b_1(V_H)`.

It does **not** follow that "the whole infinite tower is the de Rham
cohomology of one curve."  The correct statement is:

```text
one four-character target direct sum = H^1_dR(V_H);
the infinite tower = infinitely many class maps into periodic copies of
that same four-summand target.
```

The classes at `m` and `m+4` are different polynomial functions of the
same frozen `F` coefficients.  Gauge-isomorphic receivers do not make those
functions equal, independent, or exhausted after one period.  In branch P
the distinction is sharper because the four-character total torsor is
disconnected while the R7R1 calculation uses one quadratic component.

Accordingly the torsor theorem closes the **per-period obstruction-space
budget**.  It does not close R7R1's missing finite decision bound for the
infinite tower.

## 4. Row budgets and independence — REPAIR / REFUTE

The frozen `RAW_INPUT.json` gives exactly

```text
F_1,...,F_12 : 121 slots,
F_13,F_14    :   3 slots,
all positive F: 124 slots,
all positive G: 276 slots.
```

Choose coordinates on each `H^1(U,nabla_m)`.  Row `m` then contributes at
most `h_m=r-1+k_m` scalar polynomial generators.  If `I_M` is the ideal of
gate rows `23,...,M` in the 124-dimensional `F`-space, Krull's height
theorem gives the rigorous statement

```text
height(I_M) <= S(M):=sum_(m=23)^M (r-1+k_m),
dim V(I_M) >= 124-S(M).
```

This bound needs no independence assumption and remains safe under all
nonlinear dependencies.  It is only an upper bound on possible cutting.

For P, `h_m=3+[m even]`; for Q, `h_m=4+[4|m]`.  Exact recomputation gives

```text
                         first S>=121    first S>=124
branch P                      M=57             M=58
branch Q                      M=51             M=52

S_P(57)=122,  S_P(58)=126;
S_Q(51)=123,  S_Q(52)=128.
```

Therefore:

- **REFUTE** the headline that the full F-side can reach the origin at P
  row 57 or Q row 51.  At those rows the full locus still has dimension at
  least `2` or `1`, respectively.
- **REPAIR** the hard lower bound to: a 124-slot collapse is impossible
  before P row 58 / Q row 52.
- Rows 57/51 are correct arithmetic only for crossing the number `121`.
  They are not collapse thresholds in the actual 124-variable tower,
  because `F_13,F_14` enter at rows 35/36 and can absorb conditions.
- **REFUTE** any claim that collapse occurs at rows 58/52.  At and after
  those rows the height bound simply becomes silent.  It supplies no lower
  bound on the residual dimension and no upper bound on the row of
  collapse.

Likewise, "cutting rate pinned at `b_1/4` per row" must read "average
target-coordinate budget pinned at `b_1/4` per row."  The actual height
increment can be anything from zero through `h_m`; topology does not prove
row independence.

There is a further nonlinear obstruction to the proposed `GATE-MARCH`.
The reviewed triangular formula is

```text
q_n = F_n p^(n+2)/(4H^2) + NL(F_1,...,F_(n-1)).
```

For `n<=14`, a row is linear in the *new block* `F_n` but nonlinear in
earlier blocks.  For `n>=15`, the frozen polygon has `F_n=0`, so every new
row is a purely nonlinear condition on already accumulated variables (and
has no new linear handle).  Thus:

- evaluating all rows on one fixed `F*` is cheap and exact;
- computing a projector for each character is cheap and exact;
- computing the realized-codimension locus `kappa(M)`, constructing a
  generic nonzero survivor, or proving a stall is **not** reduced to one
  independent linear solve per row;
- the four residue classes are not independent computational lanes: their
  `q_n` share the same coefficients and a single dependent power-series
  recursion.

So the claimed linear-time locus solver and the proposed random-survivor
PASS/FAIL semantics are **REFUTED as stated**.  A correctness-preserving
repair is a fixed-point evaluator/Jacobian probe, explicitly non-decisive
for the global solution locus.

## 5. "G slots remain, so the F tower can never decide" — REFUTE

There is a true but strategically weak statement: the standalone gate ideal
contains no `G` variables, so its zero set is `V(I_M) x A^276_G`, and it
contains the free-coefficient origin.  The gate ideal alone is therefore
never the unit ideal.

That does **not** imply it can never decide the endpoint.  The endpoint
problem includes `D22=1`.  The frozen determinant recurrence is

```text
D_n=sum_(i+j=n)((12-j)F_i'G_j+(i-8)F_iG_j'),
```

and the frozen `G_22` window is empty.  The audited `D22` object has only
`i=1,...,14` contributions (`j=21,...,8`).  Hence, if every positive-weight
`F_i` vanishes, then

```text
D22=0 for every choice of all 276 positive G slots.
```

Therefore, if the full tower ever proves that its F-locus is supported only
at the origin, combining that F-only fact with the already-required target
`D22=1` immediately excludes the endpoint.  No elimination of the remaining
G slots is needed.  Moreover, in the actual endpoint system rows
`D1,...,D21` already couple and constrain F and G, so saying that all 276 G
slots "remain free" is true only for the isolated necessary-condition
projection, not for the endpoint ideal.

The clean strategic conclusion is the opposite of Opus's claimed no-go:
the F tower **could** decide the endpoint, but the torsor theorem gives only
a not-before bound and no evidence that the tower actually collapses its F
locus.
