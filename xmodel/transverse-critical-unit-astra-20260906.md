## Exact statement and proof

Let A be any commutative Q-algebra. Let F,G belong to A[X,W], and suppose
G(X,0)=X^2+lX+m, with l,m in A. Put s=-l/2 and Delta=G_W(s,0).
Write J=F_X G_W-F_W G_X=sum J_ij X^i W^j. Define the full Keller quotient

B=A[Z]/(all J_ij for (i,j)!=(0,0), Z J_00-1),

where any source coefficients can already be included in A and F,G. Then
Delta is a unit in B, with explicit inverse Z F_X(s,0). Indeed G_X(s,0)=0,
so J(s,0)=F_X(s,0)Delta and the following identity holds in A[Z]:

1-Z F_X(s,0)Delta
 = -(Z J_00-1)-Z sum_{i>=1} s^i J_i0.

The sum is finite. This is an ideal identity, not a field-point/radical argument.
It remains valid under arbitrary base change, including nilpotents. Thus
localizing the COMPLETE Keller quotient at Delta loses no scheme or stratum.
It does not license discarding Delta=0 from a proper subset of the Jacobian
rows that lacks this identity.

Now let F=F0+C, with G,F0 independent of the coefficients of C in a finite
rational linear space V. Suppose restriction V→Q[X] has image span{1,X}.
Choose its constant vector, a vector whose restriction is X with coefficient
beta, and a basis of V0=ker(restriction). Then

J(C,G)(s,0)=beta Delta.

Every V0 column vanishes under this evaluation row: C_X(s,0)=0 and
G_X(s,0)=0. Suppose the existing W-filtration lemma supplies n constant
positive-row pivots on V0 with invertible constant matrix M. Appending
the evaluation row to those n coefficient rows gives the block matrix

[M v; 0 Delta],

after putting the beta column last. Its determinant is det(M)Delta, hence
it is invertible on B. For the192-dimensional C spaces under consideration,
n=190 and this is an explicit191-row linear functional system.

This is NOT a constant191minor in the original coefficient-row matrix.
Evaluation is an A-linear combination of the finite W=0 coefficient rows.
It is also not a universal base-space inverse: Delta may vanish away from
the complete Keller quotient. It supplies a licensed localized final pivot,
bypassing the need to construct the global abstract Bezout left inverse.

If an independent unit Jacobian scalar j is introduced as a monic graph

All other rows, source residuals and inverse relations must still be
