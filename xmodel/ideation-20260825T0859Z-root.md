## Three highest-information mathematical bets

### Bet A — AS Greenberg component or finite carry transducer

**Idea.**  Stop treating the lifting levels as unrelated SMT formulas.  Write
the fixed-degree source/collision problem as one finite-type scheme over
`Z_3`.  At each surviving prefix, compute the cotangent-complex obstruction
class and the relative Fitting strata.  In parallel, compile each integer
product/division into a bounded schoolbook carry state, yielding a
time-homogeneous finite transducer whose vertices include every quantity
needed to determine the next residual.

**Dependencies.**  A source-complete fixed-support AS presentation; exact
collision/noninjectivity rows; integer numerator/divisibility provenance;
proof that the proposed state is sufficient and that transition is
time-homogeneous.

**Cheapest falsifiers.**  Two source prefixes with the same proposed state but
different next-state sets; an omitted restored row; an unbounded carry; or a
nonzero cotangent obstruction at both new witnesses.

**First AWS tasks.**  Continue both new states through the first unencoded
source layer.  Then compute the full Jacobian/cokernel and obstruction
pairing, quotienting source/reparametrization directions.  Build a bounded
carry transducer for one complete determinant coefficient and verify it
against raw integer replay before scaling to all rows.

**Success/stop.**  A smooth relative point gives Hensel lifting; a reachable
cycle gives an explicit eventually periodic `3`-adic lift; any infinite path
in a proved finite compatible tree gives a `Z_3` point by compactness.  A
proved acyclic graph kills this fixed family.  Stop immediately if state
sufficiency fails and enlarge the state before any SCC claim.

**Forbidden inference.**  A finite jet, modular cycle in an incomplete state,
or analytic unbounded-support lift is not a characteristic-zero polynomial
counterexample.

### Bet B — Q8 positive genus by nonsingular branch-value surplus

**Idea.**  Avoid full normalization if possible.  For monic degree-190 `H`,
remove from `rad(disc_v H)` every `w`-value supporting any affine singular
point.  Every remaining value is a genuine smooth branch value of the
normalization map to `P1_w`.  More than `378=2*190-2` such values proves
positive genus by Riemann--Hurwitz, even in wild characteristic.  Combine
with the reviewed rational `H`-contact, arithmetic `R[[w]]` attachment,
proper-specialization lemma, and primitive partition.

**Dependencies.**  Geometric integrality of `H`; exact radical discriminant;
a fail-closed elimination covering all solutions of `H=H_w=H_v=0`; reviewed
positive-genus specialization composition.

**Cheapest falsifiers.**  Residual branch-value degree at most 378; a positive-
dimensional singular locus; failure of the singular-value eliminant to contain
every singular projection; or a counterexample to the proper-model lemma.

**First AWS tasks.**  Complete the two independent singular-projection
eliminations and exact radical gcd.  In parallel continue `brnoeth`/`normal`
genus and graph interpolation.  Freeze a positive and negative branch-value
control.

**Success/stop.**  Residual degree above 378 is an immediate genus certificate;
otherwise consume exact normalization genus or one certified Rosenlicht
regular differential.  Stop the branch route if the conservative residual is
too small, without stopping normalization/graph routes.

**Forbidden inference.**  Discriminant degree, singular-scheme length, Newton
interior count, or rational-point count of the singular plane model alone is
not geometric genus.
