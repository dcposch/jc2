## Claim under review (not enlarged)

Let `S = C[x,y]` and write

```text
M = [[a, b], [c, d]] ∈ SL_2(S),
```

with the row-gradient Jacobian convention

```text
J(P,Q) = [[P_x, P_y], [Q_x, Q_y]].
```

Closed rows means the polynomial 1-forms `a dx + b dy` and `c dx + d dy` are closed:

```text
a_y = b_x,    c_y = d_x.
```

`E_2(S)` is the subgroup of `SL_2(S)` generated by the elementary matrices `e_{12}(s) = [[1,s],[0,1]]` and `e_{21}(s) = [[1,0],[s,1]]` for `s ∈ S`. The reviewed implication is only

```text
closed rows + det M = 1 + M ∉ E_2(S)
    ⇒  ∃ P,Q ∈ S with J(P,Q) = M, [P,Q] = 1, and (P,Q) is not an automorphism.
```

That is a one-way disproof certificate for the plane Jacobian conjecture. It is not the converse, not a membership test for `E_2`, not a search, and not a statement about `SL_2/E_2` as a group.

## 1. Independent recomputation of the four bridges

### 1.1 Polynomial exactness — CONFIRMED

In characteristic zero, a polynomial 1-form `ω = a dx + b dy` on `A^2` is exact if and only if it is closed. Explicit primitives:

```text
P(x,y) = ∫_0^x a(t,y) dt + ∫_0^y b(0,s) ds,
Q(x,y) = ∫_0^x c(t,y) dt + ∫_0^y d(0,s) ds.
```

Then `P_x = a`. Differentiating under the integral and using `a_y = b_x` gives `P_y = b`; likewise for `Q`. Additive constants do not change `J(P,Q)`. Termwise monomial integration is effective over `Q` (denominators are integers). This uses characteristic zero: in characteristic `p` the Poincaré lemma fails (`d(x^p) = 0`).

Independent check: for the closed Jacobian of `(x+y^2, y)`, the formula recovers the original pair up to the vanishing constants at the origin. If `det M = 1`, then `[P,Q] = 1`, so `(P,Q)` is a Keller pair. Mixed partials of any actual Jacobian are equal, so every Keller Jacobian is a closed-row matrix in `SL_2(S)` after normalizing the constant determinant to `1`.

### 1.2 Chain rule for tame plane automorphisms — CONFIRMED

Jung (1942, over `C`) and van der Kulk (1953, any field) generate `Aut(C[x,y])` by affine automorphisms and elementary shears (the amalgam `Aff_2 *_{B} J_2`).

Shear Jacobians, with the row convention above:

```text
(x, y + h(x))  ↦  e_{21}(h') ∈ E_2(S),
(x + h(y), y)  ↦  e_{12}(h') ∈ E_2(S).
```

(The second shear is affine-conjugate to the first, so one triangular factor plus `Aff_2` already generates.) Affine maps have constant Jacobian in `GL_2(C)`. Translations have Jacobian `I`.

Independent chain-rule check on `(x, y+x^2) ∘ (x+y^3, y)`: `J(F∘G) = J(F)(G) J(G)` holds identically.

### 1.3 Constant `GL_2` normalization / conjugation — CONFIRMED

To handle affine factors with determinant not equal to 1, induct on the stronger statement: every plane automorphism `H` has `JH = C_H E_H` with `C_H ∈ GL_2(C)` and `E_H ∈ E_2(S)`. Generators satisfy it. If it holds for `F` and `G`, then

```text
J(F ∘ G) = C_F E_F(G) C_G E_G
         = (C_F C_G) (C_G^{-1} E_F(G) C_G) E_G.
```

Substitution: `e_{ij}(p)(G) = e_{ij}(p∘G)` remains elementary, so `E_F(G) ∈ E_2(S)`.

Conjugation by `C_G ∈ GL_2(C)`. Over any field, write `C_G = diag(δ,1) U` with `δ = det C_G` and `U ∈ SL_2(C)`. Independent calculation:

```text
diag(δ,1)^{-1} e_{12}(r) diag(δ,1) = e_{12}(r/δ),
diag(δ,1)^{-1} e_{21}(r) diag(δ,1) = e_{21}(δ r).
```

So diagonal conjugation preserves the elementary generators. Over `C`, `SL_2(C) = E_2(C)`: Gaussian elimination, with the Weyl element

```text
[[0,-1],[1,0]] = e_{12}(-1) e_{21}(1) e_{12}(-1)
```

checked identically. Thus `U ∈ E_2(C) ⊂ E_2(S)` conjugates `E_2(S)` to itself because `E_2(S)` is a subgroup. Scalar conjugation is trivial. Feasibility’s square-root factorization `C = λ U` is available over `C` and is unnecessary: the diagonal reduction works over any field.

If `det JH = 1`, then `det C_H = 1`, so `C_H ∈ SL_2(C) ⊂ E_2(S)` and `JH ∈ E_2(S)`.

Without determinant normalization the unqualified claim “every automorphism Jacobian is elementary” is false, because `E_2 ⊂ SL_2`. The Keller case `det = 1` is exactly the case needed. This is the content of Drensky–Yu’s one-line remark (Trans. AMS 353 (2001), p. 521) that Jung–van der Kulk plus the chain rule put every automorphism Jacobian in `GE_2(K[x,y])`. For det-1 maps, `GE_2 ∩ SL_2 = E_2`: units of `S` are `C^*`, so diagonal matrices with determinant 1 lie in `SL_2(C) = E_2(C)`.

### 1.4 Non-`E_2` implication — CONFIRMED (one way)

If `(P,Q)` were a determinant-one automorphism, §1.2–1.3 would force `J(P,Q) ∈ E_2(S)`. Contrapositively, a closed-row matrix in `SL_2(S) \ E_2(S)` integrates to a Keller pair that is not an automorphism. No separately exhibited collision is required for the JC2 contradiction. In characteristic zero, a noninjective polynomial endomorphism is already a nonautomorphism; Ax–Grothendieck / Cynk–Rusek would convert injectivity into automorphy, so a nonautomorphism automatically has a collision, but exhibiting it is an independent check, not a missing lemma.

The converse — `J(P,Q) ∈ E_2 ⇒ (P,Q)` is an automorphism — is **not** part of the reviewed statement. The root card, the adversary (§3.1), and the feasibility report all warn that `M ∈ E_2` is not an automorphy certificate. That warning is **in tension with Wright 1978**, cited as standard by Drensky–Yu 2001: if the Jacobian of an endomorphism lies in `GE_2`, then the endomorphism is an automorphism (“weak Jacobian theorem”). The primary Wright PDF was not retrieved in this session (ScienceDirect blocked; DOI `10.1016/0022-4049(78)90003-8` from the 1978 JPAA pagination). Until that paper is read, the converse remains a **GAP**. The reviewed one-way implication does not use it.

The converse is false in dimension `≥ 3`: Suslin (Math. USSR Izv. 11 (1977) 221–238) gives `SL_n(K[x_1,…,x_m]) = E_n` for `n ≥ 3`, while the 2026 Alpoge–Fable three-dimensional Keller counterexample is campaign context. Elementary Jacobian is therefore not an automorphy certificate off the plane. That negative control does not touch the plane one-way lemma.

## 2. Subgroup nonmembership, not a quotient group

`E_2(S)` is a subgroup of `SL_2(S)`. For `n = 2` it is not automatically normal (Costa–Keller, *On the normal subgroups of SL(2,A)*, J. Pure Appl. Algebra 53 (1988) 201–226; announcement Bull. AMS 24 (1991) 131–135). The root card’s language “class in `SL_2/E_2`” and “nontrivial Mennicke class” is therefore unsafe as group-quotient language. The adversary and feasibility corrections are right: the certificate is plain nonmembership `M ∉ E_2(S)`.

The double orbit `E_2 M E_2` preserves nonmembership without normality. If `E_L M E_R` were elementary, then

```text
M = E_L^{-1} (E_L M E_R) E_R^{-1} ∈ E_2(S),
```

because `E_2` is a subgroup. Additive “degree-at-most-two corrections” and arbitrary deformations that leave the double orbit do **not** inherit the Cohn witness. A Mennicke-symbol map vanishing on `E_2` would be a valid invariant if one is frozen from a primary source; it is not required inside a certified double orbit.

Stable `K_1` is the wrong invariant. Suslin’s theorem says `SK_1(K[x,y]) = 0` after stabilization to rank `≥ 3`. The Cohn matrix becomes elementary in `SL_3`. The obstruction is unstable rank two.

## 3. Cohn witness lineage

### 3.1 Primary statement — CONFIRMED

P. M. Cohn, *On the structure of the GL_2 of a ring*, Publ. Math. IHÉS 30 (1966) 5–53.

- URL: `https://www.numdam.org/item/PMIHES_1966__30__5_0.pdf`
- Numdam permalink: `https://www.numdam.org/item/10.1007/BF02684355/`
- Access: 2026-08-24T06:36Z–06:47Z
- SHA-256 of the retrieved PDF: `3fa7efc1453144af36d87e27ec961a5848852756137f725650355ffcbd2d7957`

Cohn’s Proposition 7.3 (necessary condition for a `k`-ring with a degree function to be a `GE_2`-ring): of any two elements of the same degree forming a regular row, each is `R`-dependent on the other. He then takes total degree on `k[x,y]` and the regular row `(1+xy, x^2)`: same total degree 2, neither `R`-dependent on the other. Therefore the matrix

```text
C = [[1+xy, x^2], [-y^2, 1-xy]]
```

“which is clearly invertible, cannot be expressed as a product of elementary matrices.” The same argument shows `k[x_1,…,x_d]` is not a `GE_2`-ring for `d > 1`.

Independent checks on this `C`:

```text
det C = (1+xy)(1-xy) - (x^2)(-y^2) = 1.
a_y - b_x = -x,     c_y - d_x = -y.
b_x - a_y =  x,     d_x - c_y =  y.
```

The feasibility report’s “exact defects `x` and `-y`” is a sign/convention slip. Either closedness convention gives nonzero linear defects; `C` is not a Jacobian.

Two equivalent published presentations:

- Ivarsson–Kutzschebauch, Ann. of Math. 175 (2012) 45–69, p. 46: `[[1 - z_1 z_2, z_1^2], [-z_2^2, 1 + z_1 z_2]]`, which is the campaign matrix after `y ↦ -y`. They attribute non-factorization into unipotents to Cohn 1966, and point to Wright 1978 “for a connection to the Jacobian problem on `C^2`.” PDF SHA-256 `9f638b0f90c7034c8784112ccee091b9ce13684ec0895dc70739e61eb0b2a44b`.
- Chapovskyi–Kozachok–Petravchuk, arXiv:2412.03688v1 (4 Dec 2024): `[[x^2, xy-1],[xy+1, y^2]]`, det `1`, citing Cohn 1966 as [2]. PDF SHA-256 `c85a9ed67faebaecf2de88dc4571113678dfe2771f0c29eef2545e7a57e443c7`.

The 2024 paper is an unrefeered preprint. It restates Cohn non-elementarity; it does not replace Cohn 1966. Its Theorem 1 classifies every matrix in `SL_2(K[x,y])` with at least one entry of degree `≤ 2`, up to the Aut-action `A ↦ A^θ` on entries, as either a product of elementaries or a product of elementaries and a Cohn-type block of one of two forms. That classification is a literature freeze item for low-entry-degree searches. It is not a certificate that a general double-orbit member is non-elementary; the subgroup argument already supplies that inside `E_2 C E_2`.

### 3.2 What the lineage does and does not give

- **Gives:** `C ∉ E_2(S)` (in fact `C ∉ GE_2(S)`). Every `E_L C E_R` with `E_L, E_R ∈ E_2(S)` is likewise non-elementary.
- **Does not give:** a decision procedure for arbitrary `M ∈ SL_2(S)`. Specialization to one variable cannot certify non-elementarity, because `C[x]` and `C[y]` are Euclidean, so `SL_2(C[x]) = E_2(C[x])`. Cohn’s degree-dependence test applies to this row of this matrix, not automatically to a deformed first row of different degrees.
- **Aut-substitution** `C ↦ C^θ` for `θ ∈ Aut(S)` also preserves nonmembership: if `C^θ` were elementary, apply `θ^{-1}` to the factors. This is a second obstruction-preserving action, distinct from left/right multiplication. The 2024 paper uses it as a normalizer, not as a curl family.

No computational “Cohn membership oracle” was found beyond the Euclidean algorithm in one variable, Cohn’s degree-dependence obstruction, and the 2024 low-degree classification. A survivor that has left the double orbit needs a fresh non-elementarity proof.

## 4. Exact elementary actions on the two curl equations

Write `κ_1 = a_y - b_x`, `κ_2 = c_y - d_x`, so `(κ_1,κ_2)(C) = (-x,-y)`. Exact transformation laws, verified by expanding the products:

**Right `e_{12}(s)`** (col2 += s col1):

```text
κ_1' = κ_1 - s_x a - s a_x,
κ_2' = κ_2 - s_x c - s c_x.
```

On `C` this is `y^2 s_x = y` as one of the two equations, which is nonpolynomial.

**Right `e_{21}(s)`** (col1 += s col2):

```text
κ_1' = κ_1 + s_y b + s b_y,
κ_2' = κ_2 + s_y d + s d_y.
```

**Left `e_{12}(t)`** (row1 += t row2):

```text
κ_1' = κ_1 + t_y c - t_x d + t κ_2,    κ_2' = κ_2.
```

**Left `e_{21}(t)`** (row2 += t row1):

```text
κ_1' = κ_1,    κ_2' = κ_2 + t_y a - t_x b + t κ_1.
```

Length-1 actions are linear in the parameter polynomial. Exact linear algebra over `Q` (SymPy 1.14.0):
