### 8.3 What grade four constrains

* **`k10_0` : not at all.**  It does not occur in any substituted row
  (`P4_NONZERO_k_PARTIALS = 0`, an identity), and `I4 cap Q[k,z] = (z*k-1)`.
  A lift exists for every `k10_0 != 0`: take `s=t=0, u=0, v=0, z=1/k`.
* **`v = d*_3` : not at all.**  Identity again; `I4 cap Q[v] = (0)`, with
  the section `s=t=0, u=0, v` arbitrary.
* **`(s,t)` : not at all, and this is a genuine lift.**
  `I4 cap Q[s,t] = (0)`, and the explicit polynomial section
  `u = mu(s,t)`, `v = 0`, `k = 1`, `z = 1` lies on the locus for every
  `(s,t)` (`w = u - mu = 0 in V(Q2)`).  So the projection is surjective,
  not merely dominant.
* **`u` alone : not at all, and this too is a genuine lift.**
  `I4 cap Q[u] = (0)`.  Surjectivity certificate: set
  `P = 16u1-4u3+u5`, `Q = u0-4u2+2u4` (a surjective linear map
  `A^6 -> A^2`).  A point of the locus over a given `u` needs `(s,t)` with
  `2st = P`, `s^2-64t^2 = Q`.  The ring map `Q[P,Q] -> Q[s,t]` is finite:

  ```text
  s^4 - Q*s^2 - 16*P^2 = 0 ,      256*t^4 + 4*Q*t^2 - P^2 = 0
  ```

  are monic (after scaling) integral equations, and the map is dominant
  since the elimination ideal is `(0)`.  Finite + dominant over an
  algebraically closed field is surjective, so every `u in A^6` lifts.
* **The joint `(s,t,u)` : exactly two conditions, codimension two.**
  The smallest exact description is the pair

  ```text
  16*u1 - 4*u3 + u5  =  2*s*t
  u0  - 4*u2 + 2*u4  =  s^2 - 64*t^2
  ```

  These are the set-theoretic equations (they generate `sqrt`); the
  scheme-theoretic ideal is the strictly smaller
  `( Q_r(u - mu(s,t)) : r = 1,2,3,4,5,7 )`, whose reduced `dp` Groebner
  basis has 21 elements (`I4 cap Q[s,t,u]`, `CORE_STD_NCOLS=21`,
  `CORE_DIM=6`, `CORE_MULT=4`).  Equivalently, as a **Fitting-style**
  description: `u - mu(s,t)` must lie in the grade-two variety `V(Q2)`,
  whose reduction is the 4-plane
  `{16w1-4w3+w5 = 0, w0-4w2+2w4 = 0}`.

  The projection statements above are lifts, not closures; the
  codimension-two statement is about the joint variables and does not
  descend to either factor.

## 9. Ideal equality vs radical equality vs set consequence vs witness

* **Ideal equality (strongest, used):** `phi(Lambda_{4,r}) = Q_r(u-mu)`
  for each `r` -- an equality of *polynomials*, verified in two
  independent implementations.  Hence `I4 = (Q_r(u-mu))_r + (z*k-1)` as
  ideals.  Also `(z*k-1) = (1-z*k)` as ideals (mutual reduction = 1).
* **Radical equality (used, and flagged as strictly weaker):**
  `sqrt(I4) = (RA, RB, z*k-1)`, with `I4` strictly inside it.  Anything
  phrased with `RA`, `RB` alone is a statement about the *reduced* locus.
* **Set-theoretic consequence (used for the geometry):** over an
  algebraic closure `V(I4) = V(sqrt I4)`, so the displayed two affine
  equations describe the point set exactly.  They do **not** describe the
  scheme.
* **Rational witness (used):** the three points of §8.2, each verified by
  exact substitution into the literal rows, are genuine `Q`-points with
  `k10_0 != 0`.  A witness is not attainment of any bound and is not a
  claim about later grades.

## 13. Blockers and open items

1. **Upstream exhaustiveness is not verified.**  Everything is
   conditional on the displayed plane being the grade-three compatible
   rank-zero locus.  If the parallel review narrows or repairs that
   statement, §1 must be re-derived on the repaired locus; the machinery
   here transfers verbatim to any plane on which `A = 0` and `c3 = 0`.
2. **The scheme, not just the set.**  `I4` is non-reduced with
   nilpotency index 3.  Any later-grade argument that consumes "the
   grade-four stratum" must say which of `I4` or `sqrt(I4)` it means; the
   grade-five successor in §8.4 is therefore preregistered in both
   variants.
3. **No attainment claim.**  Nothing here is a floor, a price, or an
   attainment; codimension two is an exact computed value on this plane,
   not a bound transported from anywhere.
4. **Second-process replay required.**  Two implementations agree here,
   but both ran on one host under one custody chain.  A Linux replay
   against the same `raw19.sing` hash is the natural next control.
5. **Smallest successor:** `K00-G5-RANK0-PLANE` exactly as specified in
   §8.4, both variants, desk-scale, with the same mutation battery.
