## 4. New mechanism and new cross-avenue connections

### 4.1 `NEW`: bounded Greenberg--Cartier accepted-digit lookahead

For a map-only lift at `p=3`, let `F_n=(P_n,Q_n)` be Keller modulo `3^n`
with fixed total-degree cap `D`, and write

```text
F_{n+1} = F_n + 3^n (U,V).
```

Because `D F_n` reduces to the identity at the special fiber, the next
determinant residual changes by

```text
R_n  ->  R_n + U_x + V_y                 (mod 3).
```

Thus the first obstruction is the image of bounded divergence. A canonical
monomial homotopy integrates every licensed monomial except:

- Cartier classes `x^(3r+2)y^(3s+2)`;
- cap-boundary monomials whose primitive would exceed `D`.

If these vanish, the accepted next digits form an affine space under the
bounded divergence-free kernel. Split that kernel explicitly into
cap-preserving Hamiltonian directions and the characteristic-three
Frobenius/de Rham classes; never quotient a source symmetry whose composition
can raise the map degree.

The further observation is the useful one: for a **fixed depth-`n-1`
residue**, the depth-`n` accepted digit is an affine variable, and its
depth-`n+1` obstruction is again affine in that variable (the quadratic digit
term is beyond the relevant modulus at these depths). Therefore a two-level
extension question is a componentwise linear-algebra problem, even though
the union over earlier residues is nonlinear.

This suggests a finite compiler:

1. decompose the earlier residue scheme into reduced components;
2. compute the bounded divergence cokernel and a canonical particular digit;
3. parameterize the full Hamiltonian/Frobenius kernel;
4. impose the next Cartier and cap-boundary rows as an affine matrix over each
   component's coordinate ring;
5. emit Fitting/Gröbner or explicit Gaussian row-combination certificates.

This is not an all-depth theorem and not a lift. It is a way to turn each
finite successor gate into independently checkable algebra rather than a
black-box Z3 verdict.

**Post-cutoff, nonpromoted tuning evidence.** The direct `D=7` Z3 solve did
not return a verdict within a 300-second fixed-first-digit run and used about
6.8 GB RSS. In contrast, after fixing one depth-four residue, the full
