## B. FIFO protocol — PASS (STOP-biased)

Grammar H113: `b'RELEASE ' + TOKEN + b'\n'` = 73 bytes (counted). Reads H123 request `74 - len(data)` bytes, always ≥ 1 because H128 caps `len(data) ≤ 73`, so a zero-length read can never be mistaken for EOF. Memory ≤ 74 bytes; poll timeout H120 is `max(1, min(100, …))` ms; the no-data EOF branch sleeps ≤ 50 ms (H134); the open at H109 is `O_NONBLOCK|O_CLOEXEC|O_NOFOLLOW`, so it cannot block awaiting a writer. Ceiling H81–85: `min(120 − monotonic elapsed, CUTOFF − now_utc)`, refused when ≤ 0, checked at H119 before every read and again at H137/H147/H154 after the frame. H90 additionally arms `ITIMER_REAL` for the same remaining interval; its SIGALRM handler raises (H34–35), so a stalled poll/sleep is also cut. Both clocks are absolute from the same instant; neither is rebased.

Case table (traced through H118–134): no writer ever → read returns 0 with empty data → sleep/loop → cutoff → STOP. Writer opens and closes with no bytes → same → STOP. EAGAIN → `continue`. POLLERR/POLLNVAL → STOP (H121); POLLHUP alone is not a release (only data plus EOF is). Partial frame then EOF → H130 `data == expected` fails → STOP. Wrong prefix or any byte beyond 73 (duplicate frame, trailing junk, two writers) → H128 STOP. Exact 73 bytes with writer still open → next read EAGAIN forever → cutoff → STOP (no release without writer close). Exact 73 bytes then EOF → break → release path. Frame arriving after cutoff → H119 refuses before reading; frame arriving just before cutoff but processed after it → H137 refuses. Signal (TERM/INT/HUP/ALRM) during poll, read or sleep → handler raises `RuntimeError` → `except Exception` → `HOLDER_STOP_NO_DISPATCH`, exit 2; PEP 475 retry does not apply because the handler raises. Post-EOF later writer: the read end is closed in `finally` (H136) and never reopened; a second writer after a completed frame is undetectable by construction. The README states this honestly; it is a premise of the exclusive-one-writer/no-restart commitment, not something the FIFO proves. No byte of the frame reaches argv or environment: `OUTER`/`ENV` are constants (H23–25) and the token is only compared.

Untestable statically: Linux suppresses POLLHUP for a nonblocking reader until a writer has appeared, so before the first writer each iteration costs about one 100 ms poll plus 50 ms sleep; after a writer has gone, POLLHUP is immediate and the 50 ms sleep bounds the spin. Either behavior yields STOP at cutoff, never release.
