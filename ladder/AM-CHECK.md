## 0. The instrument: statements used

- (AM-SG) [Abhyankar-Moh, Crelle 260/261 (1973) approximate roots;
  Crelle 276 (1975); semigroup paper 1977 — citation inherited from the
  banked (AM-1) of SHEET6-CLASSICAL.md:150-155] For an irreducible plane
  curve of degree n with ONE place at infinity, the value semigroup at
  the place is generated by a delta-sequence (delta_0, ..., delta_h),
  delta_0 = n, all delta_i in Z_{>0}, with d_1 = delta_0,
  d_{i+1} = gcd(d_i, delta_i):
    (i)   d_{i+1} | d_i, d_{i+1} < d_i (1 <= i <= h), d_{h+1} = 1;
    (ii)  n_i delta_i > delta_{i+1}, n_i := d_i/d_{i+1}
          (equivalently delta_{i+1} < delta_i d_i / d_{i+1});
    (iii) n_i delta_i in <delta_0, ..., delta_{i-1}>.
  The candidate delta-sequence of a place with characteristic value
  exponents (m_1, ..., m_h) and delta_0 = -v(x) = n is produced by the
  approximate-root recursion delta_{i+1} = n_i delta_i + (m_{i+1} - m_i).
- (AM-DUAL) [standard local branch semigroup theory, e.g. Zariski;
  quoted from memory THIS session, flagged] For a LOCAL germ the same
  recursion applies and the inequality REVERSES:
  delta_{i+1} > n_i delta_i. The two signs are the semigroup-tier
  dichotomy finite-center vs one-place-at-infinity.
- (AM-JAC) [Abhyankar, Tata Lect. Notes 57 (1977); cf. Razar 1979;

  is an automorphism pair. Contrapositive: a Keller counterexample's f
