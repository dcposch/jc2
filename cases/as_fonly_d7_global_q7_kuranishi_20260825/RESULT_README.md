# Result

The exact unreduced affine-lift Q7 cokernel map on the 13+19 parameter chart is

```text
kappa_5=s15, kappa_6=2*t6, kappa_8=s17, kappa_9=2*t8,
```

with every other constant, linear, square, and cross coefficient zero.  Its
zero locus is the affine 28-space `t6=t8=s15=s17=0`.

This is not a canonical-digit theorem.  Direct reduction of the 64 off-grid
controls produced 36 Q8 failures and 28 Q7 rank-(9,10) failures, documenting
the carry-translation gap.
