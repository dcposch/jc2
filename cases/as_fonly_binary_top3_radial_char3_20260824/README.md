# Pure-N top-three radial identities in characteristic three

This small producer derives the exact degree-12, degree-11, and degree-10
rows of the quadratic current-digit carry for cap seven.  It consumes the
frozen binary-Wronskian helper but no large finite-state output.

Run:

```sh
./replay_all.sh
```

Expected runtime is under five seconds and memory under 20 MB.
