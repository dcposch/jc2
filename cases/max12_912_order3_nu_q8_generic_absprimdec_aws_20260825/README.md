# Selected-Q8 generic absolute primary decomposition (AWS-only)

This independent exact characteristic-zero lane forms the zero-dimensional
generic fibre over `Q(w)` of the localized six-row quotient and calls
`absPrimdecGTZ` directly, before any plane elimination.  It reports rational
primary classes, absolute conjugacy classes, and their `v` eliminants.

If there is one rational dominant component and its absolute class has one
member, the generic quotient is geometrically connected at this tier.  Eight
conjugates are the singleton-contact alternative suggested by Q8 primitivity.
Any additional rational class or ambiguous projection remains charged and
must be matched to the Q8 boundary.  Run only on AWS under the 24-hour /
256-GiB guard; output requires independent audit before promotion.
