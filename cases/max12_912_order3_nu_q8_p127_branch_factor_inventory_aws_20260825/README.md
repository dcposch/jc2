# Q8 candidate finite discriminant factor inventory

This exact `F_127` producer factors the squarefree radical of
`Res_v(H,H_v)`.  It is an input to a factor-by-factor nonsingular branch-value
certificate: for each irreducible factor `q(w)`, computation over
`F_127[w]/(q)` must decide whether `gcd(H,H_v,H_w)` is one.  Only factors with
unit three-way gcd contribute to the conservative different-degree lower
bound.  The factor inventory alone makes no genus claim.
