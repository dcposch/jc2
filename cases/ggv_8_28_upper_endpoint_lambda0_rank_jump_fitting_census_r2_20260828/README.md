# Exact rank-jump/Fitting residual census

This scope-firewalled case continues the frozen lambda=0 endpoint analysis
without changing the receiver matrix, factors, or endpoint.  It performs
only exact rational-unit row/column eliminations and a generic rank of the
resulting residual matrix.  It neither evaluates the endpoint nor computes
the next Fitting locus.

The r1 transport attempt is an adapter failure: its four archives were
extracted one directory above the frozen wrapper's expected `source/` path,
so no job registered and no algebra ran.  R2 fixed only transport/dispatch
and assigned one genuine stratum to each independently guarded AWS host.

All nine r2 jobs passed source, preregistration, EC2/DMI, exact Singular,
unit-factor, quotient-properness, selfcheck, full matrix parse, rational-unit
pivot, rank, process-group, no-orphan, and zero-swap gates.  Local stdlib
replay verified every fetched archive's `EVIDENCE.sha256` entry.

The three raw unit-factor entries are retained as
`EMPTY_UNIT_FACTOR`: C8P01=1, Q1P01=16, TRIPLE01=16.  They are not
components and were never used to form quotient rings.
