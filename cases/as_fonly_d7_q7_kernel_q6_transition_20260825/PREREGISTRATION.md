# Q7-kernel to Q6 divergence transition

Consume the canonical `e17` Q8 survivor and the exact 9-dimensional kernel
of its 19-by-18 Q7 system.  Test the zero solution and both nonzero scalar
multiples of every kernel basis vector (19 deterministic points total).

For each point, reconstruct the integer source, form

```text
G6 = F6/3 + {C,D}6 + T6,
```

asserting all precursor divisions, then restore two homogeneous degree-seven
fourth-digit forms and solve `G6+div(H7,J7)=0`.  Emit exact ranks and
substituted witnesses.  This is a basis/low-weight sample of the Q7 kernel,
not a classification of all `3^9` Q7 states or the following divided carry.
