# V82QSS q-CURRENT symbol split preregistration

This is a bounded, source-diagnostic successor to V82QS.  It does not mutate
or consume the failed q2--q10 shards and does not broaden the fixed A3 scope.

Two isolated processes, `q11` and `q16`, will run independently on Box03 and
r6d.  Each process rebuilds exact transport, FIRST, and previous/pole from the
hash-pinned reviewed V78C parent before entering CURRENT.  The process must:

1. emit the complete exact affine form `bands56[('f',3)][0]` before asserting
   whether its base is `U^6/3`;
2. hold the transported sections fixed and compile CURRENT both with and
   without the direct `q'` term;
3. retain all 40 CURRENT rows for the comparison, assert identical base pivot
   schedules and original-row replays, and prove the raw difference in degree
   `d` is `3*e*f3[d-e+1]`;
4. emit the full, omitted, and difference conormal maps and every denominator
   before any unit/expected-value assertion;
5. at q11, test q15 only as the combined lower target-shear marker
   `(delta q,delta g)=(p,f)`, never as a source coordinate or transport key;
6. at q16, distinguish a genuinely injected nonzero raw direct column from a
   zero post-GE class.

Preregistered expected endpoints are q11 full `11*U^6` at `('X0',10)` with
omitted class zero, and q16 full/omitted/difference post-GE maps all zero even
though the raw direct column is nonzero.  Any disagreement is a useful
fail-closed result, not a theorem failure to be hidden.

The calculation is square-zero, fixed-section, and localized only where the
inherited staged presentation and eventual rank-open certificates are valid.
It proves no q-neighborhood, tangent family, full TD6, SP-2, landing, or JC2
claim.  All exact execution is AWS-only under registered EC2 tags and caps.
