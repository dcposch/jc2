# Result

At each of 64 sampled canonical Q9 states, direct source substitution gives a
compatible Q8 zero-section point and a compatible Q7 system.  The Q8 rank pair
is `(13,13)` and the Q7 matrix has rank nine with ten-dimensional cokernel.

The fitted quadratic presentations all reduce to `kappa_5=s15` and
`kappa_8=s17`, with model zero count `3^17`.  That fitted count is a diagnostic,
not a whole-fibre theorem: canonical exact divisions can create higher-degree
functions, and only 64 off-grid controls were checked.  The exact promoted
payload is the 64 directly substituted zero-section witnesses.
