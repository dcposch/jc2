# Frozen sampled predecessor-state result

The 66 Box02 lanes cover two deterministic low-weight families: 39 states
in the Q8 solution kernel at fixed Q9 `e17`, and 27 states in the exact
13-dimensional Q9 Kuranishi locus with canonical Q8 sections.

All 66 Q8 states are compatible.  Eight states die at Q7.  For each of the
other 58 states, all `3^9=19683` Q7 choices were exhausted.  Every such
fibre has high-carry zero count zero and the same exact one-coefficient
quadratic-presentation hash as the frozen base branch.  The ordered high-row
stream is likewise identical to the base `R10=x^10` stream.

This is sampled-canonical in both predecessor axes.  It is exhaustive only
inside each reported Q7 fibre, so rates and absence of sampled survivors
must not be extrapolated to either full predecessor space.
