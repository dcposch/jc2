# TD6 V82P preregistration

For each `d10` and `d15`, independently reconstruct the symbolic-center TD6
transport source and require exact zero transport and first-band conormal.
Then propagate the same square-zero column through the previous X-band and
pole equations, replay every pivot combination against original rows, and
emit the exact conormal table and complete denominator factorization.

Positive controls are the nonzero raw first-band source column and the V82S
transport/first gates.  The base-q/no-dead source is the omission control.
Any nonzero previous/pole conormal is an obstruction only for that tangent
axis.  A zero table is only staged first-order survival.  Neither result is a
current-row, nonlinear, neighborhood, family, full-TD6, SP-2, or JC2 claim.

Run only on a registered AWS Linux host with the frozen source bundle.
