Date: 2026-08-26

## Repair

The dual-AWS V18 launch failed closed before any standard-basis computation:
the generated script declared the twelfth input polynomial as `E12` and then
attempted to reuse `E12` as the name of the 21-generator grade-10--12 prefix
ideal.  Singular rejected the duplicate identifier on both hosts.

V18R1 is a syntax-only repair.  It compiles the frozen V18 source and changes
exactly these three generated statements:

```text
ideal E12=...;                    -> ideal Prefix12=...;
ideal E=E12,E22;                  -> ideal E=Prefix12,E22;
ideal NoG14=std(E12+Localizers);  -> ideal NoG14=std(Prefix12+Localizers);
```

The wrapper fails unless each old statement occurs exactly once and no other
generated byte changes.  It records the pre- and post-repair script hashes.
All V18 inputs, chart substitutions, localizers, controls, validators, scope,
and upstream hashes remain fixed.  Both the original V18 freeze and this
repair freeze must validate before execution.
