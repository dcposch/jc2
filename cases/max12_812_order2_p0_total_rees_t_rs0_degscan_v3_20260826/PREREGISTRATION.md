# Preregistration: degree-scan acceleration of streaming `T-rs-0`

Date: 2026-08-26

Status: **NAVIGATION-ONLY SOFTWARE ACCELERATOR.  NO REES, CHART,
MOVING-`p`, ORDER-TWO, MAXIMUM-TWELVE, OR JC2 VERDICT.**

The frozen row-streaming V2 determines whether a candidate atom occurs in a
row by constructing `subst(Phi,x,0)-Phi` for each of 83 atoms.  This is exact
but repeats large polynomial substitutions.  V3 changes only those 581
dependency tests to Singular's exact variable degree test

```text
deg(Phi,x)>0.
```

All source formulae, rows, extraction quotients, term counts, retained cusp
coefficients, `Delta`, multiplication-back tests, negative controls, pass
gate, and validator remain byte-generated by the frozen V2 implementation.
The wrapper must find exactly seven dependency statements for each literal
candidate/inactive atom before rewriting; any count mismatch fails
compilation.

V3 runs at the same two good primes and is compared against V2.  Agreement
can accelerate discovery of the manifest but cannot replace V2 custody or
the independently reviewed exact-Q V1 confirmation.  Any disagreement is a
software defect/no-verdict.
