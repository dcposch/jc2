# AS balanced cyclotomic triangular controls

For every odd `m>=3`, this case constructs a map-only `p=3` triangular point
of total degree `D=2m+1` which is Keller modulo `3^(2m)` and terminal at the
next digit at the same degree cap.

Replay from the repository root:

```sh
python3 cases/as_fonly_p3_balanced_cyclotomic_family_20260824/replay.py
```

This is an infinite family of finite-depth compiler controls, not a compatible
all-depth tower, characteristic-zero lift, or counterexample.
