# Frozen deterministic Q9-rank-class samples

The 27 Box02 shards traversed all 33,225 corrected-Q10 states, retaining up
to four deterministic representatives per Q9 rank pair in each shard.  This
produced 168 records across six exact Q9 rank classes.

Among compatible Q9 samples, Q8 outcomes were:

```text
Q9 rank 13: 0/4 Q8-compatible;
Q9 rank 15: 4/4 Q8-compatible;
Q9 rank 16: 4/84 Q8-compatible.
```

The rank-16 class splits into fifteen Q8 matrix/RREF signatures.  Thus the
Q9 rank pair is not a sufficient transition state.  This is deterministic
sampling rather than a census inside any rank class; the displayed fractions
are not rates.
