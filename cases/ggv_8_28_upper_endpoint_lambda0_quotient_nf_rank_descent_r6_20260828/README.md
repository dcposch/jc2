# P/C8P02 quotient rank descent r6

This case closes the narrow r5 rank-adapter gap on `P` and `C8P02`.  It
replays the byte-identical r5 normal-form residual reducer, preserves every
formal size-10 and size-9 slot, computes raw and reduced determinants for all
matchable slots, and certifies exact residual rank 9 on both branches.

The result is rank-certificate-only.  No endpoint quadratic, rank-drop
locus, factor/gcd, saturation, radical, component, or survival/death claim is
made.
