## 1. Ring, elementary subgroup, and certificate language

Let S = Q[x,y] for exact replay and extend scalars to C[x,y] for the theorem.

For f in S, write

- U(f) = [[1,f],[0,1]];
- L(f) = [[1,0],[f,1]].

E2(S) means the subgroup generated by all U(f) and L(f). Every nonmembership statement below is literal membership failure in this subgroup. No quotient SL2/E2, coset multiplication, or normality of E2 in SL2 is used.

The frozen Cohn witness is

C = [[1+xy,x^2],[-y^2,1-xy]].

Its determinant is one. Its total-degree leading-form rows are

x(y,x) and -y(y,x).

Neither row is a polynomial multiple of the other. The Park leading-term necessary condition for an elementary factorization therefore certifies C not in E2(S). This certificate is also traced to Cohn's original non-GE2 construction. The alternate matrix [[x^2,xy-1],[xy+1,y^2]] used in the 2024/2026 decomposition preprint is obtained from a Cohn variant by a ring automorphism and an elementary constant rotation; it is not treated as a separate witness.

Certificate preservation rules to be used:

1. a ring automorphism sends each elementary generator to an elementary generator, in both directions;
2. if E_L and E_R are explicit products of elementary generators and E_L C E_R were elementary, multiplying by their explicit elementary inverses would make C elementary.

These are subgroup arguments only.

## 2. Bridge theorem to prove or kill

Preregistered bridge:

Let M = [[a,b],[c,d]] in SL2(C[x,y]). If

a_y = b_x,  c_y = d_x,

then the rows integrate to polynomials P,Q with M = J(P,Q). If M is not in E2(C[x,y]), then (P,Q) is a determinant-one Keller map which is not a polynomial automorphism.

Required proof certificates:

1. an explicit polynomial integration argument for each closed row;
2. a Jung-van der Kulk factorization statement from primary literature;
3. a direct chain-rule proof that the Jacobian matrix of every determinant-one plane automorphism belongs to E2(C[x,y]);
4. the chain-rule proof may use only that substitutions preserve elementary generators, constant GL2(C) matrices normalize E2 by explicit decompositions, and SL2(C) is elementary;
5. no collision is required for the logical bridge, because nonautomorphism already contradicts the Jacobian-conjecture conclusion.

Fatal bridge outcomes:

- the Cohn nonmembership lineage cannot be certified;
- the tame-to-E2 implication fails;
- integration changes the prescribed Jacobian convention;
- any step needs E2 normal in SL2(C[x,y]).

Any fatal outcome stops the root before orbit computation.

## 3. Frozen obstruction-preserving orbit

Apply the ring automorphism theta(x)=x, theta(y)=2y to C. Freeze

C_B = [[1+2xy,x^2],[-4y^2,1-2xy]].

The first row is the exact one-form

dP,  P = x+x^2y.

It is the standard Broughton critical-point-free, noncoordinate polynomial. This connection is a control and does not supply a Keller map.

The row (a,b) = (1+2xy,x^2) is unimodular, with the explicit identity

(1-2xy)a + 4y^2 b = 1.

Every determinant-one completion with this same first row must therefore differ from C_B by one left elementary shear:

M(h) = L(h) C_B.

The exact second-row closedness equation to verify is

(1+2xy) h_y - x^2 h_x = 6y.

The entire one-left-shear orbit is obstruction-preserving by the certificate rules in section 1.

No right factor, second left factor, coordinate substitution, or support widening is licensed in this run.

## 5. Global scoped theorem target

Independently of the bounded replay, attempt a theorem for the complete one-shear family.

Give monomials the weight w(x^i y^j)=i-j. The derivation

delta = (1+2xy)d/dy - x^2 d/dx

raises this weight by one. Since 6y has weight -1, only the weight -2 part of h can contribute. The intended proof gate is to derive the coefficient recurrence for

h_{-2} = sum c_n x^n y^(n+2)

and decide whether a finite nonzero solution can terminate. The result must be proved from the displayed derivation; a formal or rational solution is a control, not a polynomial survivor.

If the recurrence has a terminating polynomial solution, freeze that first survivor immediately, integrate it exactly, replay determinant and both curls, and stop. If the recurrence cannot terminate, record a scoped no-go for all determinant-one completions of the fixed Broughton row, not for the full double elementary orbit.
