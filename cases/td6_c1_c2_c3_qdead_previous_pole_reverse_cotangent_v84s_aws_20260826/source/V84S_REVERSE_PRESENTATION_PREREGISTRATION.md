# V84S preregistration — reverse-presentation cotangent control

This control is launched only after V84R2 block `(0,0)` has emitted an exact
table.  It replays the same ten `Sym^2(q2,q3,q4,q5)` source slots but replaces
the FIRST and previous/pole elimination routine by an independently coded
reverse-source-row route.  Existing pivots are eliminated in reverse variable
order, every normalized row and dependent row is replayed from the original
source rows, and no frozen V84R2 table value is read.

This generic reverse-presentation calculation dominates the originally
proposed two rational point samples as a presentation check on the common
principal open.  It is deliberately not called a full Spencer-cohomology or
formal-involutivity computation: agreement says only that the observed
quadratic cokernel value is unchanged by this exact source-row presentation.

Controls include the complete V84R2 source hash closure, exact source
combination replay for every pivot/dependent row, reverse source-row order,
reverse existing-pivot elimination order, a toy dependent-row positive
control, a plus-one RHS incompatibility control, all V84R2 q-boundary
singleton/omission controls, and all quadratic Taylor/inverse/pair-symmetry
controls.  A nonzero exit, missing table, failed control, or source mismatch is
no mathematical verdict.

Execution is AWS/Linux only, under an 8 GiB virtual-memory cap and a six-hour
timeout.  Scope is the fixed source-typed A3 section on the same licensed
generic principal open, through previous/pole, for this ten-pair block only.
No current-row, rank-drop-fibre, nonlinear-family, TD6, SP-2, landing, or JC2
claim is licensed.
