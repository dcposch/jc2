# V82QSS3 source prose version note

The frozen source archive's `V82QSS3_EMPTY_MAP_ERRATUM.md` names
python-flint 0.8.0.  The actual AWS launch streams print
`python_flint_version=0.9.0`.  This is a documentation-only version typo: the
load-bearing statement is the executable type fact that `tri.CTX` is the
`fmpq_mpoly_ctx` and `tri.ONE == tri.CTX.constant(1)`.  Both hosts execute that
typed positive control before any expensive transport.  The source archive is
not mutated.
