# Result

The 64 frozen predecessor files contain 13 zero and 51 nonzero Q8 affine
particular vectors.  Their zero `first_witness` vectors are RREF fibre
coordinates, not coefficient vectors.  `particulars.json` displays and hashes
every affine particular.

The original producer substituted the actual affine particular in each case,
so the 64 pointwise Q8/Q7 compatibility statements survive.  Only the claim
that all 64 coefficient vectors themselves were zero is retracted.
