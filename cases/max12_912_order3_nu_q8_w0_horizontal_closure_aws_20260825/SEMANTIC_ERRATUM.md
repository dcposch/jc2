# Semantic erratum to the frozen preregistration

Date: 2026-08-25  
Status: **INTERPRETIVE REPAIR; FROZEN INPUT BYTES UNCHANGED**

The displayed ideal

```text
Bsrc = (I + (x5*(x3-2*x5))) : w^infinity
```

is exactly the `w`-horizontal part of the **boundary incidence**
`X intersect V(x5*(x3-2*x5))`.  It is not, without a separate
component/decomposition argument, literally the union of irreducible
components of `X` that are generically contained in that divisor: it may
also contain horizontal divisors or subvarieties cut inside a broader source
component.

The generated ideals, launch inputs, and set-theoretic complement split are
unchanged.  Every successor must use the boundary-incidence formulation and
must not infer irreducible-component containment from `Bsrc` alone.
