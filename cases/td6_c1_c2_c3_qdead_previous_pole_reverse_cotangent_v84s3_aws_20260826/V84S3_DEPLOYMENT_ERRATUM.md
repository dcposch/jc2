# V84S3 nonmutating deployment repair

V84S2 passed its matched reverse toy controls on both AWS hosts, then exited
before exact source algebra because the imported immutable V84R2 `main()`
requires an `AWS_RUN_TAG` beginning `td6_v84r2_k2_`.  The actual V84S2 tags
began `td6_v84s2_reverse_`.  This is a pre-algebra deployment failure and
carries no mathematical verdict.

V84S3 preserves every parent byte and the true registered outer tag.  After
asserting and printing that outer tag, it temporarily presents the immutable
parent with the explicitly printed compatibility tag
`td6_v84r2_k2_v84s3_proxy_<outer-tag>`, restores the outer tag afterward, and
prints both facts.  The proxy changes neither source rows nor arithmetic.
Any nonzero exit or table disagreement still fails closed.
